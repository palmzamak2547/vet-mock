# VetMock Study Squad — 3D Character Blueprints & Blender Production Guide
> สเปกพิมพ์เขียว 3D, ค่าสี, สัดส่วนโมเดล Chibi และคู่มือการปั้นใน Blender สำหรับแสดงผลบน Three.js

เอกสารนี้ระบุรายละเอียดทางเทคนิคสำหรับการขึ้นโมเดล 3D ของมาสคอตประจำคลินิกทั้ง 5 ตัวละครใน **VetMock Study Squad** เพื่อให้ได้ขนาดไฟล์เบา สวยงามในสไตล์ **Soft Clay / Vinyl Figurine** (สไตล์ Pop Mart / Animal Crossing) และพร้อมใช้งานบนเว็บผ่าน **Three.js (.glb)**

---

## 1. ข้อกำหนดทางเทคนิคทั่วไป (Global 3D Specs for Three.js)

| หัวข้อ | ข้อกำหนด (Specification) | เหตุผล |
| :--- | :--- | :--- |
| **Polygon Budget** | 3,000 – 6,000 Triangles ต่อ 1 ตัวละคร | ปลอดภัยสำหรับ Mobile Web (iOS Safari / Android) โหลดไว ไม่หน่วงเฟรมเรต |
| **Scale / Units** | 1 Blender Unit = 1 Meter (ตัวละครสูง ~0.80 - 0.90 m) | มาตรฐานสเกลสำหรับ Three.js และระบบแสง PBR |
| **Topology** | Quads-dominant (โพลีกอน 4 เหลี่ยมเป็นหลัก), มี Loop รอบข้อต่อ | ดัดงอและเคลื่อนไหวตามกระดูกได้เนียน ไม่บิดเบี้ยว |
| **Material / Shading** | Blender Principled BSDF → Three.js `MeshStandardMaterial` | Roughness 0.45–0.55, Subsurface 0.05–0.1 (ให้ความรู้สึกผิวดินน้ำมัน/ยางนุ่ม) |
| **Facial System** | Curved Decal Plane แปะแนบผิวหน้า + Texture Atlas (PNG) | เปลี่ยน UV Offset หรือ Texture สลับตากะพริบ/ยิ้มได้ลื่นไหล ไม่เปลืองกระดูก |
| **Export Format** | `.glb` (Binary glTF) พร้อม Embedded Textures & Animations | รวมไฟล์เดียวจบ โหลดง่ายผ่าน `GLTFLoader` |

## 2. พิมพ์เขียวและสเปกรายตัวละคร (Character Blueprints)

### 🐮 1. มูชา (Moocha) — สัตว์ใหญ่ & โค-ปศุสัตว์
*สายพันธุ์: ลูกวัวโคนม (Holstein Calf) | บุคลิก: ใจดี ขยัน อบอุ่น เป็นมิตร*

- **สัดส่วนร่างกาย (Chibi Ratio)**: 2.2 Heads tall (หัว 45%, ลำตัว+ขา 55%)
- **หัว (Head)**: ทรงลูกเต๋าขอบมน (Rounded Cube) ขยายด้านข้างเล็กน้อย ปากและจมูกยื่นออกมารูปไข่แบน
- **หูและเขา**: หูทรงใบไม้ป้าน ตกลงด้านข้างเล็กน้อย ปลายมน, เขาคู่เล็กมนมาก (Nub horns) สีเหลืองครีม, หูขวามี **Ear Tag สีเหลืองสด** (ป้ายประจำตัวปศุสัตว์)
- **เครื่องแต่งกาย**: ชุดเอี๊ยมยีนส์ขาสั้น (Overalls) สายพาดบ่าคู่, หูฟังตรวจโรค (Stethoscope) สายยางสีน้ำเงินคล้องรอบคอ, รองเท้าบูทยางกันน้ำสีเขียวขี้ม้า
- **Color Palette**:
  - ผิวขนหลัก: Milk White (`#FDFDFD` / `(0.97, 0.97, 0.97)`)
  - ลายแต้มวัว: Slate Black (`#2B2D42` / `(0.02, 0.03, 0.06)`)
  - จมูก/ในหู: Blush Pink (`#FFB4A2` / `(1.00, 0.45, 0.36)`)
  - ป้ายหู (Tag): Vet Yellow (`#FFD166` / `(1.00, 0.63, 0.13)`)
  - เอี๊ยมยีนส์: Denim Blue (`#4A7C9B` / `(0.06, 0.20, 0.33)`)
  - หูฟังแพทย์: Cyan Tube (`#0284C7` / `(0.00, 0.23, 0.58)`)
  - รองเท้าบูท: Olive Boot (`#386641` / `(0.04, 0.13, 0.05)`)

### 🐿️ 2. ไกลดี้ (Glidy) — สัตว์แปลก & สัตว์ป่า (Exotic)
*สายพันธุ์: ชูการ์ไกลเดอร์ (Sugar Glider) | บุคลิก: คล่องแคล่ว ขี้สงสัย ตาโต ช่างสำรวจ*

- **สัดส่วนร่างกาย**: 2.0 Heads tall (หัว 50%, ลำตัว 50%) ลำตัวเพรียวเบา
- **หัวและดวงตา**: ตาโตกลมมากกินพื้นที่เกือบ 40% ของใบหน้า จมูกชมพูสามเหลี่ยมจิ๋ว
- **พังผืดและหาง**: แนวสันพังผืดบางๆ จากข้อมือถึงสีข้างลำตัว, หางยาวนุ่มฟู ม้วนงอนปลายเล็กน้อย
- **เครื่องแต่งกาย**: เสื้อกั๊กนักสำรวจสีกากี (Safari Vest), กระเป๋าสะพายแล่งหนังสีน้ำตาล (Crossbody Satchel)
- **Color Palette**:
  - ขนตัวหลัก: Soft Glider Grey (`#E2E8F0` / `(0.75, 0.80, 0.88)`)
  - แถบกลางหัว/หลัง: Charcoal Stripe (`#334155` / `(0.03, 0.05, 0.09)`)
  - ท้อง/คาง: Cream Frost (`#F8FAFC` / `(0.94, 0.96, 0.98)`)
  - จมูก/อุ้งมือ: Peach Paw (`#FDA4AF` / `(0.98, 0.35, 0.42)`)
  - เสื้อกั๊ก: Khaki Sand (`#C2B280` / `(0.53, 0.44, 0.21)`)
  - กระเป๋าสะพาย: Saddle Leather (`#8B5E3C` / `(0.25, 0.11, 0.04)`)

### 🐷 3. พอร์กี้ (Porky) — อายุรศาสตร์สุกร (Swine)
*สายพันธุ์: ลูกหมูชมพู (Piglet) | บุคลิก: เรียบร้อย สุภาพ มุ่งมั่น เป็นคุณหมอมือโปร*

- **สัดส่วนร่างกาย**: 2.3 Heads tall (รูปร่างกลมป้อม นุ่มนิ่ม)
- **หัวและจมูก**: แก้มป่องสองข้าง จมูกหมู (Snout) วงรีแบน มีรูจมูกคู่บุ๋มมน หูสามเหลี่ยมพับตกลงมาข้างหน้า (Floppy ears)
- **เครื่องแต่งกายและพร็อพ**: ชุดสครับแพทย์คลินิกสุกรสีฟ้าพาสเทล (Light Blue Scrubs), ถือคลิปบอร์ดตรวจโรค (Medical Chart Clipboard)
- **Color Palette**:
  - ผิวหลัก: Warm Piglet Pink (`#FCE7F3` / `(0.97, 0.79, 0.90)`)
  - จมูก/ใบหูด้านใน: Deep Pink Acc (`#F472B6` / `(0.90, 0.16, 0.45)`)
  - ชุดสครับแพทย์: Clinic Aqua Blue (`#BAE6FD` / `(0.49, 0.78, 0.98)`)
  - คลิปบอร์ด: Wood Clip (`#D4A373` / `(0.65, 0.36, 0.17)`)
  - รองเท้าบูท: Forest Green (`#2D5A27` / `(0.02, 0.10, 0.02)`)

### 🦦 4. โอโตะ (Oto) — คลินิกสัตว์น้ำ (Aquatic)
*สายพันธุ์: นากทะเล (Sea Otter) | บุคลิก: ร่าเริง ชอบเล่นน้ำ กระฉับกระเฉง ผู้พิทักษ์สายน้ำ*

- **สัดส่วนร่างกาย**: 2.1 Heads tall ลำตัวทรงลูกแพร์ (Pear shape)
- **หัวและขน**: หัวทรงกลมมน หูเล็กกลมสองข้างชิดศีรษะ โซนปากแก้มคางเป็นสีครีมสว่าง ตัดกับขนตัวสีน้ำตาล
- **เครื่องแต่งกายและพร็อพ**: แว่นดำน้ำวิทยาศาสตร์ (Diving Goggles) คาดบนหน้าผาก, เสื้อชูชีพกู้ภัยสีส้มสด (Orange Life Vest), อุปกรณ์ถือ: หลอดทดลองวิทยาศาสตร์น้ำ
- **Color Palette**:
  - ขนตัวหลัก: Chestnut Fur (`#78350F` / `(0.18, 0.04, 0.01)`)
  - ขนหน้า/อก: Sea Foam Cream (`#FEF3C7` / `(0.98, 0.89, 0.54)`)
  - เสื้อชูชีพกู้ภัย: High-Vis Orange (`#F97316` / `(0.94, 0.16, 0.01)`)
  - แว่นดำน้ำ: Sky Blue Goggle (`#38BDF8` / `(0.04, 0.50, 0.94)`)
  - เลนส์แว่น: Ocean Aqua Glass (`#A5F3FC` / `(0.36, 0.88, 0.96)`)

### 🐴 5. โคลเวอร์ (Clover) — เวชปฏิบัติม้า (Equine)
*สายพันธุ์: ลูกม้าเกาลัด (Baby Pony) | บุคลิก: สง่างาม สุภาพ ฉลาด มีความเป็นผู้นำ*

- **สัดส่วนร่างกาย**: 2.4 Heads tall
- **หัวและแผงคอ**: สันจมูกโค้งมนเรียวยาว แผงคอหนานุ่มสีบลอนด์ทองปัดเป๋ข้าง มีแต้มสีขาวรูปดาวกลางหน้าผาก (Star Mark)
- **เครื่องแต่งกาย**: เสื้อกาวน์สูทสัตวแพทย์ม้าสีเขียวหัวเป็ดเข้ม (Hunter Green Blazer) ปกเชิ้ตขาว หูฟัง Stethoscope
- **Color Palette**:

  - แผงคอและหาง: Golden Mane (`#FDE047` / `(0.97, 0.74, 0.06)`)

  - เสื้อสูทแพทย์: Hunter Green Coat (`#14532D` / `(0.01, 0.08, 0.02)`)

### 🐥 6. ชิคกี้ (Chicky) — เวชศาสตร์สัตว์ปีก (Avian & Poultry Medicine)
*สายพันธุ์: ลูกเจี๊ยบขนปุย (Fluffy Chibi Chick) | บุคลิก: กระตือรือร้น เสียงใส ช่างสังเกต*

- **สัดส่วนร่างกาย**: 1.8 Heads tall (หัวกลมโต ลำตัวทรงไข่ป้อม)
- **หัวและขนหงอน**: ปอยขน 3 แฉกบนกระหม่อม, จะงอยปากสามเหลี่ยมสีส้มสดมน, ดวงตาสดใสเป็นประกาย
- **เครื่องแต่งกายและพร็อพ**: หมวกศัลยกรรมคลินิกสัตว์ปีกสีเขียวเทล (Teal Surgical Cap) พร้อมตรากากบาทแดง, เอี๊ยมผ้ากันเปื้อนสีขาว, หูฟังตรวจโรค
- **Color Palette**:
  - ขนตัวหลัก: Buttercup Yellow (`#FDE047` / `(0.99, 0.88, 0.28)`)
  - ปอยขนหงอน: Soft Canary (`#FEF08A` / `(1.00, 0.94, 0.54)`)
  - จะงอยปาก/เท้า: Tangerine Coral (`#F97316` / `(0.98, 0.45, 0.09)`)
  - หมวกและหูฟัง: Scrub Teal (`#0D9488` / `(0.05, 0.58, 0.53)`)
  - ผ้ากันเปื้อน: Lab White (`#F8FAFC` / `(0.97, 0.98, 0.99)`)

- **เครื่องแต่งกาย**: เสื้อกาวน์สัตวแพทย์สีขาว (White Lab Coat) ปักลายอุ้งเท้า, หูฟังตรวจโรคสีน้ำเงินรอยัลบลู (Royal Blue Stethoscope)
