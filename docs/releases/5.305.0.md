# 5.305.0: สไลด์ใต้เฉลยแสดงหน้าที่สองด้วย

## สิ่งที่นิสิตเห็น

- **ข้อที่คำตอบอยู่บนสไลด์สองหน้า แสดงหน้าที่สองพร้อมไฮไลต์ต่อใต้หน้าแรก** เช่น หัวข้ออยู่หน้าหนึ่งและรูปอยู่หน้าถัดไป
  แต่ละหน้ามีชื่อสไลด์และเลขหน้าของตัวเอง ชุดคาดการณ์ One Health ปลายภาคได้หน้าที่สอง 23 ข้อ
- หน้าสรุป One Health ปลายภาคมีภาพสไลด์ 24 หน้า จาก 22 หน้า บรรทัดที่อ้างหน้าที่เป็นหน้าที่สองของเฉลยก็ได้ภาพด้วย

## What changed

- `src/lib/evidence.js`: `evidenceFor` reads the further pages a row files after the hash (5.304.0) and returns them
  as `more`, in reading order. Each page is checked on its own: a document index the file does not hold, a page that
  is not a whole number from 1, a width or height that is not positive, or a box that is not four finite numbers
  leaves that page out. A malformed first page still shows nothing, whatever follows it, and an edited question still
  drops every page.
- `src/components/EvidenceSlot.jsx`: the card draws the first page and then each further page under it, with the same
  frame, citation line and full view, painted together.
- `src/components/AnswerEvidence.jsx`: with two pages under one answer there are two "ดูสไลด์ที่ใช้เฉลย" buttons, so
  each button is described by its own citation line (`aria-describedby`): a screen reader says which page it opens.
- `src/lib/wrap-slide.js`: `slideIndex` also reads the further pages, so a wrap-up line that cites one finds its
  picture. The One Health final wrap-up goes from 26 lines that find a page to 28, and from 22 pages drawn to 24.
- `src/lib/wrap-slide.js` and `src/views/WrapUpView.jsx`: which line of an item draws which page is now worked out
  once per item (`itemSlides`) before the lists draw. The list used to mark a page as drawn while it rendered, so
  React StrictMode, which renders each list twice in development, found every page taken on the second pass and drew
  none. Production rendered once and was not affected; a development server now draws the same slides as a build.
- `docs/ANSWER-EVIDENCE.md`: the card shows every page of a row.

## Checks

- `tests/unit/answer-evidence.test.mjs`: an answer that rests on two pages carries the second; eight malformed further
  pages (an unknown document, a page 0, a page 2.5, a zero width, a box of three numbers, a box that is not a list,
  a page that is not a list, a document named by a string) are each left out; an empty list adds nothing; a
  malformed first page shows nothing; an edited question drops every page.
- `tests/unit/wrap-slide.test.mjs`: a page filed only as a further page has its picture; an item shows each page
  once, under the first line that cites it, and the same slides when it is drawn a second time.
- The unit tests that read these modules pass (149).
- The One Health final wrap-up on a development server draws 24 slide frames, the pages per item the citations give
  (3, 2, 5, 1, 2, 1, 3, 1, 3, 1, 2, 0). Before this change it drew none there.
