# 5.216.4: the last middle dots outside `src/`

#226 (5.216.2) cleaned the app's own screens. Three places outside `src/` still carried "·" as a
separator, and this release removes them.

| Place | Found | Changed | Rule |
|---|---|---|---|
| `public/blog/*.html` (4 articles) | 97 | 97 | a comma for a list, a plain clause break (a space, with "และ", "ส่วน", "ซึ่ง" or "แล้ว" where the sentence needed one) for two clauses, `\|` before the brand in a `<title>`, a comma in meta rows and descriptions, a line break and a gap between the footer's links |
| `public/templates/*.svg` (4 templates) | 29 | 29 | a comma in the label text only |
| `vca/src/lib/topic-label.js` | 1 rule | 1 | a stored dot becomes ", " (was " — ") |

The VCA rule: no topic name in `curriculum.js` holds a middle dot today (0 of 1,086 labels), so the
rule is a guard for a name that gains one. The curriculum's own two-part names already use a comma
(112 labels) as often as a dash (84), and a dot gives no way to tell a category from a qualifier, so
a comma is the neutral choice and a colon is not used.

Checks: the four SVGs and the other four templates parse as XML; `cleanTopicLabel` called directly
returns "Mycotoxin, Zearalenone" for "Mycotoxin · Zearalenone". `vca/tests/unit/topic-label.test.mjs`
imports the generated bank, which is not built here, so CI runs it.
