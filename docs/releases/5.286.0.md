# 5.286.0: การ์ดของฉัน แต่งการ์ดได้เอง และแชร์เป็นรูปได้

## สิ่งที่นิสิตเห็น

- **การ์ดของฉันในโปรไฟล์:** ใต้การ์ดชื่อมีการ์ดของนิสิต (ชื่อ รูป ปี จำนวนข้อที่ทำ วันต่อเนื่อง และถ้วย)
  นิสิตใหม่ได้การ์ดที่ดูเสร็จแล้วโดยไม่ต้องแตะอะไร ปุ่ม "ปรับแต่งการ์ด" เปิดหน้าปรับแต่ง
- **ปรับแต่งการ์ด:** เลือกพื้นหลัง (ทุกแบบเลือกได้ตั้งแต่แรก) กรอบ (เส้นบางได้ตั้งแต่แรก กรอบอื่นได้เมื่อมีถ้วยที่บอกไว้ใต้กรอบ)
  ถ้วยที่จะโชว์ได้ 3 ใบ และคำใต้ชื่อ การ์ดเปลี่ยนให้เห็นทันทีและบันทึกทันที บรรทัดใต้ตัวเลือกบอกว่าบันทึกไว้ที่ไหน
  ไม่มีอินเทอร์เน็ตหรือบันทึกไม่สำเร็จก็บอก การ์ดยังอยู่ในเครื่อง ออกจากหน้าแล้วกลับมาก็ยังอยู่
  "คืนค่าเริ่มต้น" เปลี่ยนพื้นหลัง กรอบ ถ้วย และคำใต้ชื่อกลับเป็นแบบแรก ชื่อและรูปไม่เปลี่ยน (แก้ได้ที่การ์ดชื่อในโปรไฟล์)
- **แชร์การ์ด:** ทำรูปการ์ดแบบเดียวกับที่เห็นในหน้าปรับแต่ง สีสว่างหรือมืด ขนาดสตอรี่หรือโพสต์
- **สมาชิกกลุ่มติว:** แท็บสมาชิกแสดงสมาชิกแต่ละคนเป็นการ์ด ไม่แสดงตัวเลขการเรียนของเพื่อน

## สิ่งที่เจ้าของเห็น

- ขั้นฐานข้อมูล (ยังไม่ได้ทำ): `supabase/migrations/20261116150000_profiles_card_style.sql` เพิ่มคอลัมน์ `profiles.card_style`
  และฟังก์ชัน `card_styles` กับ `set_card_style` วิธีย้อนกลับอยู่บนสุดของไฟล์
  ก่อนทำขั้นนี้ แอปไม่ถามหาคอลัมน์นี้เลย เพื่อนในกลุ่มเห็นการ์ดแบบเริ่มต้น และการ์ดที่แต่งไว้อยู่ในเครื่องของนิสิต
  หลังทำ เพื่อนในกลุ่มเห็นการ์ดที่แต่งไว้ เครื่องใหม่ที่เข้าบัญชีเดียวกันได้การ์ดเดิม ไม่ต้องตั้งค่าอะไรเพิ่ม

## ตรวจอย่างไร

- `tests/unit/card-style.test.mjs`: การ์ดแบบเดียวกันวาดเป็นหน้าจอและเป็นรูปแชร์ ได้คำเดียวกัน สีเดียวกัน (สว่างและมืด)
  และตัดภาพพื้นหลังแบบเดียวกัน, ก่อนมีคอลัมน์ไม่มีคำขอใดเอ่ยชื่อคอลัมน์ ถามครั้งเดียวต่อการเปิดแอป เพื่อนเห็นการ์ดแบบเริ่มต้น,
  หลังมีคอลัมน์เพื่อนเห็นแบบที่เลือก ค่าที่ไม่ใช่การ์ดถูกทิ้ง, การบันทึกบอกผลเมื่อออฟไลน์ ถูกปฏิเสธ และค่าเสีย
- `tests/e2e/custom-studio.spec.js`: เปิดจากการ์ดในโปรไฟล์ เลือกแล้วเห็นทันที ออกแล้วกลับมายังอยู่ กรอบที่ยังไม่ได้บอกวิธีได้
  คืนค่าเริ่มต้นได้, รูปแชร์ขนาด 1080 x 1920, บนจอโทรศัพท์การ์ดอยู่บนจอตลอดและปุ่มไม่อยู่ใต้แถบล่าง
- ภาพทุกหน้าที่ 390 x 664, 820 x 1180, 1180 x 820 และ 1280 สว่างและมืด
