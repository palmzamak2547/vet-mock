# 5.224.0: the exam card, session and results fixes, verdict colours under every palette, a lighter download

Five branches parked since 11 Nov, folded onto main `dc78f0c0` in one branch (`claude/fold-exam-fixes`). This release
changes the exam session, scoring, the result outbox, backups and the question card: it needs two independent
reviews before it merges (AGENTS.md, exam flow).

## What changed

One part per branch. The lanes' own notes (reproductions before and after, measurements, guards) were in
`docs/releases/pending/*.md` on each branch and are summarised here; their full text is in this branch's history.

  `lint:option-letters` join `lint:data`.
- 23 flag notes reworded (claims unchanged); vca 8047 held back (unreadable scan in options C to E);
  epidemiology 213524 marked as a documented conflict (`claude/bank-notes`).

### Part 2. Learner fixes for the exam session (`claude/learner-fixes` `2c1e80c8`)

Fill-in items give feedback in practice (ตรวจคำตอบ, marks per blank, one pairing with scoring); one move per double
tap (a 120 ms floor and a 250 ms lapse in `useExamSession.js`); one exit dialog for X and Back (`src/lib/exit-set.js`);
the results page opens on the score and the next step (one mascot, the 60% mark once, a one-row reminder); matching
stems drop "ลากการ์ด" on screen (`src/lib/match-stem.js`); the card works at 200% zoom and below 280 px; each tap in
a timed exam is written to the device at once, with a notice when it cannot be; the exam clock cannot be stretched by
setting the device clock back (`src/lib/exam-clock.js`); Thai look-alike spellings of a key score as the key
(`thaiSpelling` in `src/hooks/utils.js`, which the server's re-score imports); "today" for the daily question, quests,
XP and the goal starts at Bangkok's midnight (`src/lib/study-day.js`).

### Part 3. Exam data gaps (`claude/exam-data-gaps` `c18a01d9`, 11 commits cherry-picked from `refs/pr/212..`)

Unsent exam results travel in every backup and are restored once, for the signed-in account only; a refused record no
longer blocks the outbox (`api/exam-result.js` answers 409 `result_conflict`); waiting results with no owner are named
in the notice; `unordered` and `keywords` are in the question revision, with the previous revision of poultry 4002 and
4012 accepted until 1 Jan 2027 (`question-revision-window.test.mjs` fails after that date while the window is open); a
resumed parked set takes the bank's current questions when their options are unchanged
(`src/lib/exam-recovery.js`, `src/lib/parked-resume.js`).

### Part 4. Verdict colours (`claude/verdict-colours` `02c17e29`, draft pull request #234)

Right and partly right read `--clr-right*` and `--clr-part*`, set by no palette; wrong reads `--clr-rose*`; text on
`--clr-rose-soft` reads `--clr-rose-soft-text`. The timed exam's question map paints the current question in ink.
Guard: `tests/unit/verdict-colours.test.mjs`. Its own number, 5.217.3, is void; its two changelog lines are in this
entry.

### Part 5. First-load weight (`claude/debt-weight` `d7fbd79e`)

`origin-move.js` + `move-base.js`, `native-app.js` and `MotionSettings.jsx` + `haptics.js` leave the first load
(`src/lib/move-gate.js`, `src/lib/native-detect.js`; `lazyOnly` in `perf-budgets.json`); a Vite transform drops
`sourcePages`, `_pdfRef`, `_confidence` from question banks and `sources` from wrap-up bullets
(`scripts/strip-unread-fields.mjs`; 54 chunks, 78,635 B gzip less); 17 dead CSS classes removed; 100vh paired with
dvh outside the question screens. The move give-up notice waits while a session is on screen.
