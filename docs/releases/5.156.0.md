# 5.156.0: lasso select and blank notebooks (writing studio 1)

First slice of the writing studio (`docs/WRITING-STUDIO.md`), PR #53, merged as `1ec12035`.

- **Lasso** (`src/lib/lasso.js`, `src/components/LassoLayer.jsx`): draw a loop to take strokes (60% of a stroke's
  points inside; erasers never), drag to move, a corner to resize (uniform, line width scales, 0.2x to 6x). An action
  bar for colour, duplicate, delete and done; Esc, Delete, Ctrl/Cmd+D. Every action writes new strokes plus tombstones
  for the old ids, so sync needs nothing new; undo and redo take a lasso action back as one step.
- **Blank notebooks** (`src/lib/notebook.js`, `src/components/NotebookShelf.jsx`): blank, 8 mm lines, 5 mm grid,
  5 mm dots or Cornell paper. A notebook is a PDF the app makes, opened in the same reader under `nb:<id>`.
