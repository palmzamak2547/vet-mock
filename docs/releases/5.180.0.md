# 5.180.0: the API runs in Singapore

Infrastructure only, so no changelog entry (Rule 2). Every function without a region of its own
ran in iad1 (Washington), the Vercel default. Students are in Bangkok, Supabase is in
ap-southeast-1 and the library's R2 bucket `vetmock-library` is in APAC, so each API call crossed
the Pacific once for the student and again for every database call. A library PDF crossed it
twice more: R2 (APAC) to the function in iad1, then back to the student.

- **Default region sin1** (`vercel.json` `regions`). AI chat and transcription were already there.
- **Ten functions stay in iad1.** The rule: a function stays while its calls in a row to services
  in US East outnumber one (the student's own Pacific crossing) plus its calls to Supabase or R2.
  The limiter (Upstash) is in US East, as are Resend and Anthropic.
  - agent-action, grade-summary: 2 limiter calls, then the model.
  - transcribe-handwriting: 2 limiter calls, then Anthropic first.
  - study-coach: 2 to 4 limiter calls; wiki-explain: 1 to 4.
  - playlist: 1 limiter call, 3 with the YouTube key, plus one before each further YouTube request.
  - fetch-external-doc: up to 4 limiter calls for a guest.
  - send-feedback: 2 limiter calls and Resend.
  - exam-result and race-start would be faster in sin1 (about 230 and 440 ms), but they sit in the
    exam flow, which does not change before the Year-5 finals end on 4 Dec. Their limiter calls
    fail closed, and from sin1 each one would cross the Pacific.
- mochi-voice moves: its admin status check makes no limiter call, and each of its actions is
  faster in sin1.
- `tests/unit/function-regions.test.mjs` holds the layout. When the limiter moves to Singapore,
  the US-bound list shrinks to the functions bound to Resend or Anthropic, and the exam-flow pair
  moves after 4 Dec.

## Where the limiter is (measured, not assumed)

| Probe (from Bangkok, warm, 1 Nov) | Median |
|---|---|
| `/api/tts` answering 405, no outside call (iad1), curl, 9 runs | 387 ms |
| `/api/playlist` answering 400 after one limiter call (iad1), curl, 9 runs | 395 ms |
| `ai-chat` (sin1) time to its first byte, two limiter calls in a row, 6 warm requests in 23 h of logs | 443 to 539 ms |

One limiter call costs about 8 ms from iad1 and about 220 ms from sin1, so it sits in US East.
