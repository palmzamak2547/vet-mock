# 5.180.0: the API runs in Singapore

Infrastructure only, so no changelog entry (Rule 2). Every function without a region of its own
ran in iad1 (Washington), the Vercel default. Students are in Bangkok, Supabase is in
ap-southeast-1 and the library's R2 bucket `vetmock-library` is in APAC, so each API call crossed
the Pacific once for the student and again for every database call. A library PDF crossed it
twice more: R2 (APAC) to the function in iad1, then back to the student.

- **Default region sin1** (`vercel.json` `regions`). AI chat and transcription were already there.
- **Seven functions stay in iad1**: agent-action, grade-summary, mochi-voice, playlist,
  study-coach, transcribe-handwriting, wiki-explain. Each makes two to four limiter calls in a
  row, and the limiter (Upstash) is in US East, so from sin1 each call would add a Pacific round
  trip. They move when the limiter moves to Singapore (Palm's account); the pin list then empties.
- `tests/unit/function-regions.test.mjs` holds the layout: the default, the pins and their reasons.

## Where the limiter is (measured, not assumed)
