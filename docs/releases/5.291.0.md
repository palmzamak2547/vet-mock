# 5.291.0: เส้นที่เขียนด้วยปากกาบน PDF ไม่หายเมื่อฝ่ามือยังวางอยู่บนจอ

## สิ่งที่นิสิตเห็น

- **เขียนบน PDF ในโหมดรับเฉพาะปากกา:** ถ้าวางฝ่ามือบนจอก่อนลงปากกา แล้วยกปากกาขึ้นขณะที่ฝ่ามือยังวางอยู่
  เส้นที่เพิ่งเขียนเคยหายไป และปากกาค้างอยู่ในสถานะกำลังเขียนจนกว่าจะลงปากกาครั้งต่อไป
  ตอนนี้เส้นนั้นถูกเก็บไว้ตามปกติ
- การวาดทับภาพและช่องเขียนคำตอบด้วยลายมือใช้ตัวจัดการปากกาและนิ้วชุดเดียวกับหน้า PDF แล้ว
  การใช้งานเหมือนเดิมทุกอย่าง ตัวเลือก "รับเฉพาะปากกา" ของการวาดทับภาพยังจำไว้หลังโหลดแอปใหม่เหมือนเดิม

## ตรวจอย่างไร

- `tests/unit/ink-engine.test.mjs`: ลำดับ pointer จำลอง ฝ่ามือลง ปากกาลง ปากกาลาก ปากกายก ฝ่ามือยังวางอยู่
  ก่อนแก้ไม่ผ่าน (เส้นหาย) หลังแก้เส้นถูกเก็บ และมีข้อทดสอบของตัวเลือกแต่ละข้อที่การวาดทับภาพและช่องลายมือใช้
- `tests/unit/handwriting-pad-engine.test.mjs` และ `tests/unit/image-annotator-engine.test.mjs` รันส่วนประกอบจริง:
  นิ้วเขียนได้จนกว่าจะใช้ปากกา, ฝ่ามือหลังใช้ปากกาไม่เป็นเส้น, ล้างแล้วนิ้วเขียนได้อีก, เมาส์ปุ่มขวาไม่เขียน,
  โหมดรับเฉพาะปากกาไม่วาดด้วยนิ้วและขึ้นคำบอก, ตัวเลือกนี้ยังอยู่หลังโหลดใหม่และปิดไว้ตั้งต้น
- การทดสอบเดิมของหน้า PDF ช่องลายมือ และการวาดทับภาพผ่านทั้งหมดโดยไม่แก้ข้อตรวจ
