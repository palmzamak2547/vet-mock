# 5.251.0: หน้าแรกและหัวหน้าไม่ขยับเมื่อข้อมูลมาถึงทีหลัง และตัวหนังสือที่จางอ่านได้ชัดขึ้น

ชุดแก้ที่สองจากการกวาดหน้าจอวันที่ 16 พ.ย. 2569: สิบสี่ข้อจากยี่สิบข้อที่พบ ชื่ออวัยวะใน Atlas ที่ทับกันยังไม่ได้แก้ในรุ่นนี้

## สิ่งที่นิสิตเห็น

- **หัวหน้า:** กลุ่มปุ่มขวาเป็นส่วนที่เหลือของแถว ชิดขอบขวา ระดับ XP ข้อที่บันทึกไว้ และ streak วางทางซ้ายของปุ่มค้นหา
  ระดับ XP มาก่อนเพราะมักมาถึงช้าสุด ชื่อบัญชีมีความกว้างคงที่ 100 px ชื่อที่ยาวกว่านั้นตัดด้วย … ที่ 601 ถึง 1199 px
  ซ่อนชื่อและแถบ XP เหมือนมือถือ หัวหน้าไม่ขึ้นบรรทัดใหม่อีก ที่ 390 px ปุ่มค้นหา บัญชี และธีมไม่เลื่อนแล้ว
  ที่ 1024 px นิสิตที่มี streak ข้อที่บันทึกไว้ และ XP ห้าหลัก เคยเห็นปุ่ม XP ทับปุ่มช่วงสอบ 16 px (แตะแล้วเปิดแผง XP) ตอนนี้ห่างกัน 159 px
  ปุ่มข้อที่บันทึกไว้ที่มาถึงทีหลังยังทำให้ปุ่มปี/ช่วงสอบหดลง (ตัดด้วย …) อยู่ในรายการที่ยังเหลือ
- **หน้าแรก:** แผนฝึกวันนี้รอจนอ่านบัญชีและโหลดโจทย์ของปีเสร็จ (นานสุด 6 วินาที) โดยจองที่ 200 px บนจอกว้าง และ 270 px บนมือถือ
  พร้อมข้อความ "กำลังจัดแผนจากประวัติการฝึก" ที่โปรแกรมอ่านหน้าจออ่านให้ฟัง แผนที่แสดงแล้วไม่กลับไปเป็นที่จองอีก
  (สลับปีหรือกลับมาหน้าแรกระหว่างโหลดโจทย์) ป้ายต้อนรับรออ่านบัญชีนานสุด 6 วินาทีเท่ากับแผน ป้ายต้อนรับครั้งแรกไม่ขึ้นระหว่างอ่านบัญชี ตัวเลขวันที่นับขึ้นจองความกว้างของเลขสุดท้าย
  ขั้นรองของแผนยังวางสองช่องต่อแถว แต่คำบนปุ่มเป็นลูกศร (ทั้งการ์ดคือปุ่ม) ชื่อวิชาจึงไม่ถูกตัดคำว่า "ข้อ" ไปบรรทัดใหม่
  แผนรอเฉพาะเมื่อมีประวัติหรือกำลังอ่านบัญชี ผู้ใช้ใหม่ที่ยังไม่มีประวัติเห็นการ์ดข้อแรกทันที
  วัดด้วยการกวาดหน้าแรก: รายวิชาเคยเลื่อน 93 ถึง 114 px ตอนนี้เลื่อน 2 ถึง 37 px เมื่อแผนสองขั้นมาแทนที่จอง
  (ที่จองเท่าแผนสามขั้น), หัวหน้าที่ 1180 และ 1280 px เหลือ 0
  ชื่อวิชากับจำนวนข้อในขั้นของแผนอยู่ด้วยกันเสมอ ("8 ข้อ" ไม่แยกบรรทัด)
- **ความต่างสี:** ช่องคะแนนว่างใช้กรอบเส้นประแทน opacity 0.4, ตัวเลขในปุ่มกรองหน้าคณาจารย์ไม่จางด้วย opacity,
  ข้อความในการ์ด "หน้านี้ขัดข้อง" ใช้ `--clr-ink`, สีบทบาทผู้ร่วมเขียนโจทย์ใช้ token ตัวอักษร (`--clr-ocean-text` และอื่นๆ) แทนสีตายตัว
- **ขนาดปุ่ม:** แถวรองของแถบข้าง ปุ่มบัญชี และเครื่องมือ PDF สูง `--touch-min` (44 px)
- **ชื่อทับกัน:** แผนที่ความถี่ตัดชื่อเดือนที่ห่างจากเดือนถัดไปไม่ถึง 4 สัปดาห์ การ์ดอาจารย์วางป้ายวิชาไว้บรรทัดใต้ชื่อ
- **เมนูธีม:** เปิดแล้วโฟกัสไปที่โหมดที่ใช้อยู่ Tab ออกนอกเมนูแล้วปิด Escape ยังคืนโฟกัสให้ปุ่ม

## ข้อที่ปิดโดยไม่ต้องแก้

- **หัวข้อหน้าแรกของผู้มาใหม่ในโหมดมืด:** บน main ปัจจุบัน หัวข้ออ่านได้เต็มที่ทั้ง 390 และ 820 px
  ค่าที่ต่ำในการกวาดมาจากการวัดตัวหนังสือระหว่างกำลังค่อยๆ ปรากฏ ตัววัดรอให้ animation ที่มีความยาวจบก่อนวัดแล้ว
- **วงกลมโหลดของหน้ากลุ่ม:** แผงโหลดมีข้อความ "กำลังโหลดกลุ่มของคุณ…" อยู่ในแผงเดียวกัน การกวาดไม่พบวงกลมไร้ข้อความ

## เครื่องมือกวาด

- `VMX_DEFECT_SHOTS=<folder>` เก็บรูปของแต่ละหน้าหลังนิ่ง (`VMX_DEFECT_CLIP=<selector>` เฉพาะส่วน) ไว้ตรวจด้วยตา
- ตัววัดความต่างสีรอ animation ที่กำลังเล่นและมีความยาวจบ (นานสุด 2.5 วินาที) ก่อนอ่านสี

## ตรวจอย่างไร

- `npm run sweep:defects` แบบแคบเฉพาะหน้าแรก คณาจารย์ สัดส่วนคะแนน คิวรอตรวจ ร่วมเขียนโจทย์ และกลุ่ม
  สี่ขนาด สองโหมด ก่อนและหลังแก้
- หัวหน้า: `tests/e2e/header-no-overlap.spec.js` วัดกล่องของทุกปุ่มบนหัวหน้าทุกความกว้างจาก 320 ถึง 1440 px
  ทั้งนิสิตที่มี streak ข้อที่บันทึกไว้ XP ห้าหลักและชื่อยาว และนิสิตที่ไม่มีชิ้นใดเลย: ไม่มีสองปุ่มทับกัน แตะกลางปุ่มถึงปุ่มนั้น
- หน้าแรก: `tests/unit/home-plan-wait.test.mjs` ตรวจเงื่อนไขการรอของแผนและป้ายต้อนรับ และ `role="status"` ของที่จอง
