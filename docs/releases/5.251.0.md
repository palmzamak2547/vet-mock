# 5.251.0: หน้าแรกและหัวหน้าไม่ขยับเมื่อข้อมูลมาถึงทีหลัง และตัวหนังสือที่จางอ่านได้ชัดขึ้น

ชุดแก้ที่สองจากการกวาดหน้าจอวันที่ 16 พ.ย. 2569 (`work/defect-sweep/FINDINGS.md` แถว 4, 7 ถึง 20)
รูปก่อนและหลังอยู่ใน `work/defect-sweep/fixes/` (ไม่อยู่ใน repository)

## สิ่งที่นิสิตเห็น

- **หัวหน้า (แถว 4):** กลุ่มปุ่มขวาเป็นส่วนที่เหลือของแถว ชิดขอบขวา ระดับ XP ข้อที่บันทึกไว้ และ streak วางทางซ้ายของปุ่มค้นหา
  ระดับ XP มาก่อนเพราะมักมาถึงช้าสุด ชื่อบัญชีมีความกว้างคงที่ 100 px ชื่อที่ยาวกว่านั้นตัดด้วย … ที่ 601 ถึง 900 px
  ซ่อนชื่อและแถบ XP เหมือนมือถือ หัวหน้าไม่ขึ้นบรรทัดใหม่อีก ที่ 390 px ปุ่มค้นหา บัญชี และธีมไม่เลื่อนแล้ว
  ปุ่มข้อที่บันทึกไว้ที่มาถึงทีหลังยังทำให้ปุ่มปี/ช่วงสอบหดลง (ตัดด้วย …) อยู่ในรายการที่ยังเหลือ
- **หน้าแรก (แถว 8, 7):** แผนฝึกวันนี้รอจนอ่านบัญชีและโหลดโจทย์ของปีเสร็จ (นานสุด 6 วินาที) โดยจองที่ 270 px
  พร้อมข้อความ "กำลังจัดแผนจากประวัติการฝึก" ป้ายต้อนรับครั้งแรกไม่ขึ้นระหว่างอ่านบัญชี ตัวเลขวันที่นับขึ้นจองความกว้างของเลขสุดท้าย
  ขั้นรองของแผนเรียงทีละบรรทัด ชื่อวิชาไม่ถูกตัดคำว่า "ข้อ" ไปบรรทัดใหม่ข้างปุ่ม
  วัดด้วยการกวาดหน้าแรก: รายวิชาเลื่อน 93 ถึง 114 px เหลือ 0 ถึง 14 px, หัวหน้าที่ 1180 และ 1280 px เหลือ 0
- **ความต่างสี (แถว 10, 12, 18, 20):** ช่องคะแนนว่างใช้กรอบเส้นประแทน opacity 0.4, ตัวเลขในปุ่มกรองหน้าคณาจารย์ไม่จางด้วย opacity,
  ข้อความในการ์ด "หน้านี้ขัดข้อง" ใช้ `--clr-ink`, สีบทบาทผู้ร่วมเขียนโจทย์ใช้ token ตัวอักษร (`--clr-ocean-text` และอื่นๆ) แทนสีตายตัว
- **ขนาดปุ่ม (แถว 9, 13):** แถวรองของแถบข้าง ปุ่มบัญชี และเครื่องมือ PDF สูง `--touch-min` (44 px)
- **ชื่อทับกัน (แถว 14, 15, 16):** Atlas วัดกล่องชื่อแต่ละชื่อครั้งเดียว ชื่อที่จะทับชื่อที่วางแล้วเป็นจุดแทน (ชื่อที่เลือกวางก่อนเสมอ)
  แผนที่ความถี่ตัดชื่อเดือนที่ห่างจากเดือนถัดไปไม่ถึง 4 สัปดาห์ การ์ดอาจารย์วางป้ายวิชาไว้บรรทัดใต้ชื่อ
- **เมนูธีม (แถว 11):** เปิดแล้วโฟกัสไปที่โหมดที่ใช้อยู่ Tab ออกนอกเมนูแล้วปิด Escape ยังคืนโฟกัสให้ปุ่ม

## แถวที่ปิดโดยไม่ต้องแก้

- **แถว 19 (หัวข้อหน้าแรกของผู้มาใหม่ในโหมดมืด):** บน main ปัจจุบัน หัวข้ออ่านได้เต็มที่ทั้ง 390 และ 820 px
  ค่าที่ต่ำในการกวาดมาจากการวัดตัวหนังสือระหว่างกำลังค่อยๆ ปรากฏ ตัววัดรอให้ animation ที่มีความยาวจบก่อนวัดแล้ว
- **แถว 17 (วงกลมโหลดของหน้ากลุ่ม):** แผงโหลดมีข้อความ "กำลังโหลดกลุ่มของคุณ…" อยู่ในแผงเดียวกัน การกวาดไม่พบวงกลมไร้ข้อความ

## เครื่องมือกวาด

- `VMX_DEFECT_SHOTS=<folder>` เก็บรูปของแต่ละหน้าหลังนิ่ง (`VMX_DEFECT_CLIP=<selector>` เฉพาะส่วน) ไว้ตรวจด้วยตา
- ตัววัดความต่างสีรอ animation ที่กำลังเล่นและมีความยาวจบ (นานสุด 2.5 วินาที) ก่อนอ่านสี

## ตรวจอย่างไร

- `npm run sweep:defects` แบบแคบเฉพาะหน้าแรก คณาจารย์ Atlas สัดส่วนคะแนน คิวรอตรวจ ร่วมเขียนโจทย์ และกลุ่ม
  สี่ขนาด สองโหมด ก่อนและหลังแก้
