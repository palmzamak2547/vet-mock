# 5.300.0: ฝึกเฉพาะข้อสอบเก่าได้ทุกหัวข้อ

## สิ่งที่นิสิตเห็น

- **ปุ่ม ทุกข้อ กับ ข้อสอบเก่า เหนือรายการหัวข้อ:** กดข้อสอบเก่าแล้วการ์ดรวมทุกหัวข้อ การ์ดชุดรวม และการ์ดหัวข้อ
  นับเฉพาะข้อที่เคยออกสอบจริง (ข้อเดียวกับที่การ์ดโจทย์ติดป้ายข้อสอบเก่า) แตะการ์ดไหนก็ได้ชุดตามตัวเลขนั้น
  หัวข้อที่ไม่มีข้อสอบเก่าอยู่ที่เดิม ขึ้นว่า ไม่มีข้อสอบเก่า และไม่เปิดชุดว่าง ปุ่มสรุปกับ VetWiki ของหัวข้อนั้นยังกดได้
  เครื่องจำที่เลือกไว้ วิชาที่ไม่มีข้อสอบเก่าในช่วงสอบนั้นไม่แสดงปุ่มและไม่กรองอะไร
- **หน้าตั้งค่าการฝึก:** บรรทัดสรุปบอกว่า ข้อสอบเก่า 10 ข้อ และใน "ปรับเอง" มีแถว ข้อที่ใช้ เปลี่ยนได้เฉพาะชุดนั้น
  จำนวนข้อที่ตั้งเองกลับมาเมื่อเปลี่ยนกลับเป็นทุกข้อ โหมดสอบใช้แถวเดียวกันได้ ชุดที่ผู้ใช้เก็บเอง
  (บุ๊กมาร์ก ข้อที่ผิด จุดอ่อน) ไม่มีแถวนี้
- **หน้าผลคะแนน:** ทำหัวข้อนี้อีก 5 ข้อ และขั้นต่อไปของชุดข้อสอบเก่ายังเป็นข้อสอบเก่า และบอกไว้ในบรรทัดของปุ่ม
- **กลางภาคกับปลายภาคไม่ปนกัน:** ชุดข้อสอบเก่าแยกตามช่วงสอบที่เลือกเหมือนชุดปกติ และเมื่อช่วงสอบนั้นไม่มีข้อสอบเก่า
  ของวิชาหรือหัวข้อที่เลือก จะได้ศูนย์ข้อ ไม่ดึงข้อของอีกช่วงสอบมาแทน

## What changed

- `src/lib/exam-pool.js`: `onlyPastPaper` moved after the paper filter, as the last narrowing step,
  and skipped for curated pools. Before the paper, a topic whose past papers all sat the other paper
  emptied the paper filter, and its never-empty guard then served those other-paper questions under a
  switch whose count (this paper's table) said 0. New helpers: `pastOnlyShown(practiceMode)` (the row
  is drawn for the plain pools only, the type picker's rule) and `pastPapersOf(pool)`.
- `src/views/TopicSelectView.jsx`: the switch (`vmx-topic-past-only` on the device), counts from the
  same tables as the percentage chip, a topic with questions but no past paper marked `data-no-past`
  and its main button disabled, a tap arms the config screen with `setPastOnly`.
- `src/views/ConfigView.jsx`: the ข้อที่ใช้ row, the summary naming the set, the empty line naming the
  choice that emptied it, and a pool switch that keeps the count's meaning (the app's own count follows
  the new size; a count the student picked comes back).
- `src/App.jsx`: `pastOnly` lives for one config visit like `panicPending` and is read only where its row
  is drawn; the config count comes from the same `buildExamPool` call with `onlyPastPaper`; the session
  remembers `sessionPastOnly` (also in the in-flight record, for a resumed set) for the results page.
- `src/lib/exam-pool.js`, again: past papers only never takes the paper filter's never-empty guard, and
  `pastPapersOf(pool, set)` asks the set's paper, so the config row counts what its chip serves.
- `src/lib/study-catalog.js`: collection cards get `pastPaperCount`. Without it รวมหมาหอน (repro-lect)
  would print 0 past papers under the switch while its button served 47, and the practrum one 0 for 3.
