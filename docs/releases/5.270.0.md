# 5.270.0: ข้อความ "ยังไม่มีเนื้อหา" ขึ้นเมื่อว่างจริงเท่านั้น และบรรทัดใต้หัวข้อของปี 6 ตรงกับข้อมูล

## สิ่งที่นิสิตเห็น

- **การ์ดวิชา:** การ์ดที่ไม่มีข้อสอบและไม่มีสรุป เคยขึ้น "ยังไม่มีเนื้อหา" และถูกปิดทันที ก่อนที่แอปจะอ่านคลังเอกสารเสร็จ
  หรือเมื่ออ่านคลังเอกสารไม่ได้ ตอนนี้ขึ้นเมื่ออ่านคลังเอกสารแล้วว่าไม่มีเอกสารเลยเท่านั้น ระหว่างนั้นขึ้น "กำลังโหลด…"
  และถ้าอ่านไม่ได้ ขึ้น "ยังโหลดคลังเอกสารไม่ได้"
- **หัวข้อที่มีแต่บทความ VetWiki:** ป้ายอ่านออกเสียงของปุ่มบอกว่ามีบทความ ไม่บอกว่ายังไม่มีเนื้อหา
- **ปี 6:** บรรทัดใต้หัวข้อบอกว่าเปิดอ่านคลังเอกสารได้ เฉพาะเมื่อมีวิชาของปีนั้นที่มีเอกสารจริง
- **คิวซ่อมโจทย์:** `docs/content-repair-queue.csv` เคยมี 65 แถวจากวันที่ 7 ก.ย. ทั้งที่ประตูส่งโจทย์ปิดไว้ 212 ข้อ
  ตอนนี้ไฟล์สร้างจากรายการเดียวกับประตู (`npm run regen:delivery`) และ `lint:delivery` ตรวจว่าตรงกัน
  ทั้ง 65 แถวเดิมยังรอตรวจอยู่จริง ไม่มีแถวที่แก้เสร็จแล้ว

## ตัวกัน

`tests/unit/empty-state-copy.test.mjs` ตรวจทุกที่ที่ขึ้นข้อความว่าไม่มีเนื้อหา และ "รอข้อมูล" ใน `src/data/scores.js` ที่เป็นแค่คอมเมนต์
