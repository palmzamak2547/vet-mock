# 5.157.0: answer tape (writing studio 2)

Second slice of the writing studio, PR #55, merged as `b3c3931d`.

- Tape tool: drag a strip over an answer on a slide or in a notebook; tap to peel, tap again to cover; a
  "peeled/total" button peels or covers them all. A fade replaces the peel under reduced motion.
- Stored as a stroke `{ mode: 'tape' }`, so it syncs, tombstones, undoes and moves with the lasso. Never painted into
  the ink or the exported PDF. Peeled is for this sitting only: every open starts covered.
- A tap is not a tape (under 1.2% of the page on a side), and the student is told so.
