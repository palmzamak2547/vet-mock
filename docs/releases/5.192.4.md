# 5.192.4: sync keeps custom questions, streaks and conflicting edits; true quest and review counts; fair option order; sign-in recovers

## What shipped

Lane fixes from the same subsystem sweep as 5.192.3: two independent reviews per finding, a test seen failing
first, each lane's diff read again before it was picked.

1. **Sync** (`src/lib/user-data-atomic.js`, `user-data-sync.js`, `custom-question-ids.js`; the sync RPC and the
   migrations untouched): new custom-question IDs skip every ID the account has stamped, deleted ones included; a
   guest workspace's questions go up as created, so a same-ID collision is offered as the custom-ID recovery instead
   of replacing the account's question; `mergeStreak` compares Bangkok day numbers (it compared `Date.parse` of
   milliseconds, NaN); a second conflict joins the open conflict prompt instead of deleting the losing edit.
2. **Study progress** (`quests.js`, `sm2.js`, `sr-scheduler.js`, `badges.js`): quest state is re-read when another tab
   changed it; "ถึงรอบพรุ่งนี้" counts Bangkok's tomorrow; the quest streak reads 0 once a run has ended; the
   corrected-mistakes badge reads history in time order.
3. **Practice sets** (`current-scope.js` new, `question-prediction.js`, `exam-pool.js`, `option-shuffle.js`, regenerated
   `q-counts.js`): the current-scope and predicted sets take the paper from `lib/exam-scope.js` (topic first), so 30
   verified equine-medicine questions join the final's set (year 5 under 1-final: 40 to 70); the shuffle no longer
   pins 95 content rows in 64 questions that merely start with ทั้ง, and pins All correct / All incorrect /
   ไม่มีข้อใดกล่าวผิด (8 rows in 7 questions). Pinned options 252 to 165; pinned keys 66 before and after.
4. **Sign-in** (`line-liff.js`, `supabase.js`, `google-gis.js`, `useAuth.js`): sign-out clears the stored LIFF login;
   the Android app shows the auth server's refusals instead of a second, redirect sign-in; a failed Google script
   load is retried; an offline open re-reads the profile when the device is back online or the tab is seen.
5. **Share card** (`share-card/kit.js`): a cut paragraph is a layout problem, so a long VetWiki title steps down to a
   size that shows it whole (13 of 224 topic cards change, drawn in Chromium with the real fonts).
6. **Document reader** (`markdown-render.js`, `SRSessionView.jsx`): `\|` is a literal pipe in a table cell; link
   targets are read back with the exact inverse of `escapeHtml` and may hold balanced parentheses; the review card
   draws `imagePath` through `safeImageUrl`.
7. **Feedback usage log** (`api/_lib/feedback-usage.js`): HMAC-SHA256 fingerprints under a server-only key.
8. The 5.192.3 release record.

Checks before merge: 46 affected unit files for the first five lanes, 439/439, and the day-boundary set under
TZ=UTC 151/151; `lint:q-counts`; the share-card, reader and feedback sets 124/124; `lint:changelog-latest`,
`changelog-voice`, `lint:ui-copy`.
