# 5.293.0: Swine Medicine ปลายภาค: เฉลยข้อ pseudorabies ในสุกรขุนอายุ 15 สัปดาห์แก้เป็นอาการทางเดินหายใจแบบความรุนแรงต่ำ

## สิ่งที่นิสิตเห็น

- **ข้อสอบเก่า Vet 80 เรื่อง pseudorabies ในสุกรขุนอายุราว 15 สัปดาห์:** เฉลยเปลี่ยนจาก "ถูกทุกข้อ"
  เป็น "อาการทางระบบทางเดินหายใจ แบบความรุนแรงต่ำ" เพราะสุกรรุ่นและสุกรขุนมีอาการทางเดินหายใจเป็นหลักและตายน้อย
  อาการรุนแรงเกิดเมื่อมีเชื้อแทรกซ้อนจนเป็น PRDC เท่านั้น คำอธิบายเขียนใหม่ให้เห็นรูปแบบอาการตามกลุ่มอายุ
- **สรุปก่อนสอบ Swine Medicine ปลายภาค:** บรรทัดที่อ้างข้อนี้แก้ให้ตรงกับเฉลยใหม่

## หลักฐาน

- สไลด์ปีนี้ หน้า 46: growing pigs มี respiratory signs และ low mortality ยกเว้นมีเชื้อแทรกซ้อน
- Merck Veterinary Manual, Pseudorabies in Pigs: respiratory disease เป็นปัญหาหลักใน weaned and growing pigs
  อัตราตาย 1-2% ใน growing-finishing pigs
- หน้าข้อสอบของรุ่นพี่: วงกลมข้อ 2 และคีย์ท้ายหน้าข้อ 19 = 2

## ตรวจอย่างไร

- ข้ออื่นในคลัง Swine เรื่องอาการ pseudorabies ตามกลุ่มอายุ (8357, 105596, 209052, 209401) ตรวจกับสไลด์เดียวกัน เฉลยตรงกันอยู่แล้ว
- `npm run regen:all`, `npm run regen:share-bank`, `npm run lint:data:all`
