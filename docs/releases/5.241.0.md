# 5.241.0: FMD Module 1 ถึง 4 ในหน้าระบาดวิทยา ตารางสอนขึ้นเร็วขึ้น และรายงานข้อผิดพลาดเก็บแค่ไฟล์ของเว็บเอง

## สิ่งที่นิสิตเห็น

- **ระบาดวิทยา แท็บสื่อเรียนและโหมดสอบ:** การ์ดใหม่ "FMD Module 1 ถึง 4" อยู่ถัดจากบทเรียน Module 5
  ในการ์ดมีลิงก์สี่บรรทัด แต่ละบรรทัดเปิดหน้าเว็บบทเรียนของอาจารย์ผู้สอนในแท็บใหม่
  หน้าเหล่านี้อยู่นอก myCourseVille และไม่มีไฟล์ให้เก็บเข้าคลัง VetMock จึงไม่คัดลอกเนื้อหา แค่พาไปที่หน้าเดิม
  ทั้งสี่ลิงก์เปิดได้ (ตอบ 200) เมื่อ 15 พ.ย. 2569 การ์ดกว้างเต็มแถว ลิงก์สูงอย่างน้อย 44 px
- **ตารางสอนในหน้าตาราง (ปี 5):** ตารางสอนที่ยาวเกินหนึ่งหน้า A4 จัดหน้าเร็วขึ้น
  การจัดหน้าลองวางแถวทีละชุดหลายรอบ รอบที่ซ้ำกัน (แถวชุดเดิม หน้าเดิม ขนาดตัวอักษรเดิม) คำนวณครั้งเดียวแล้วใช้ผลเดิม
  และตารางที่ไม่พอหนึ่งหน้าแม้ใช้ขนาดที่แน่นที่สุด ไม่ต้องลองขนาดที่หลวมกว่าอีก
  จำนวนหน้าและขนาดตัวอักษรที่ได้ เหมือนเดิมทั้ง 11 วิชา
- **รายงานข้อผิดพลาด:** เก็บชื่อไฟล์และเลขบรรทัดเฉพาะเมื่อไฟล์นั้นมาจากเว็บ VetMock เอง (`/assets/` ของโดเมนที่เปิดอยู่)
  ไฟล์ของส่วนขยายเบราว์เซอร์หรือของเว็บอื่นไม่ถูกเก็บ แม้ชื่อทางจะลงท้ายด้วย `assets/ชื่อไฟล์.js` เหมือนกัน
  ข้อความในหน้าความเป็นส่วนตัว "ชื่อไฟล์โค้ดของเว็บพร้อมเลขบรรทัด" จึงตรงตามที่เขียน

ไฟล์: `src/data/lessons.js`, `src/views/TopicSelectView.jsx`, `src/styles.css`,
`src/lib/share-card/course-doc-card.js`, `src/lib/client-diagnostics.js`, `tests/unit/no-silent-failures.test.mjs`

## เดินดูที่ขนาดมือถือ

เปิดเซิร์ฟเวอร์ dev แล้วเดินด้วย Chromium ที่ 390 x 664 px (ความละเอียด 3 เท่า, เครื่องช้าลง 4 เท่า)
เปิดเอกสารทั้ง 22 ฉบับ (ประมวลรายวิชา 11 และตารางสอน 11) จากหน้าตาราง ทุกฉบับจัดหน้าได้ไม่มีอะไรล้น
หน้าไม่เลื่อนออกด้านข้าง และกล่องเอกสาร ปุ่มปิด ปุ่มดาวน์โหลดอยู่ในจอทั้งหมด

## เวลาจัดหน้าตารางสอน

วัดในหน้าเว็บที่โหลดฟอนต์แล้ว เครื่องช้าลง 4 เท่า ที่ 390 x 664 px แต่ละวิชาจัดหน้า 7 รอบ ใช้ค่ากลาง
รวมทั้ง 11 วิชา:

| | รอบที่ 1 | รอบที่ 2 |
|---|---|---|
| ก่อน | 6,896 ms | 8,638 ms |
| หลัง | 4,904 ms | 5,828 ms (รอบที่ 3: 4,619 ms) |

ลดลงราวหนึ่งในสาม ผลที่ได้ (จำนวนหน้าและขนาดที่เลือก) ตรงกันทุกวิชาทั้งก่อนและหลัง
การจัดหน้ายังทำต่อเนื่องในครั้งเดียว ยังไม่ได้แบ่งเป็นช่วง
