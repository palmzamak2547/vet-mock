# 5.202.0: a table reads as a table

Palm, 11 Nov 2026: "พวกคำถาม โจทย์ หรือเฉลย ... เราสามารถเก็บความ polish ได้อีกเยอะ เช่นบางข้อ Epidem
ทำเป็นตารางให้อ่านง่ายได้". A 2x2 written as a sentence makes the student build the table in their head
before the question starts.

## What a student sees

- **Epidemiology, 19 questions on 6 shared passages.** The passage is a table now: the ELISA and
  feline leukaemia 2x2s, the detection-dog study, calving and mastitis, the Leptospira risk factors
  (21 rows) and the struvite regression (15 rows). Four of them had been transcribed with a note such
  as "ตัวเลขแต่ละกลุ่มเรียงเป็น จำนวน positive herds, จำนวน negative herds และ prevalence (%)" in front of
  rows of bare numbers.
- **12 explanations in COM IV, Repro Lecture and Herd Health** already held a table in the summaries'
  pipe form. The card showed them as bars and dashes; it draws them now, on the card, in the written
  reveal, the review list, the daily question and the SR card.
- A passage that holds a table sits above the question at every width. Beside it, in 42% of the card,
  a table's Thai cells wrapped syllable by syllable.
- Read aloud, a table is said a row at a time, each value after its column's name.

## How

| | |
|---|---|
| `src/lib/rich-blocks.js` | cuts a text into prose and tables with their offsets; a text with no table comes back as the same string |
| `src/components/RichBlocks.jsx` | draws them; the prose still goes through the renderer it always did |
| `src/components/SmartPassage.jsx` | highlights keep their offsets in the passage's text, so a table between two runs of prose shifts nothing, and a selection that starts or ends in a table marks nothing |
| `src/lib/tts-text.js` | `stripForSpeech` says a table a row at a time |
| `scripts/lint-question-tables.mjs` | in `lint:data`: no table in a stem, an option or a model answer; every table row belongs to a table that parses; 2 to 6 columns |
| `docs/QUESTION-STANDARD.md` C5 | the rule for writers |

## What was checked

- **The numbers.** The six passages were converted by a script that refuses a passage whose numbers
  differ from the original's, each counted (the same multiset before and after). Nothing was added:
  no row total that the passage did not give.
- **Nothing else changed.** A text with no table renders and is spoken exactly as before: the unit test
  reads every stem, option, explanation and passage of the bank (over 30,000 texts) and compares.
  No pre-recorded clip is renamed: stems and explanations were not edited, a passage is not read
  aloud, and the 12 explanations with tables are in subjects that have no clips.
- **By eye.** Five questions at 1280 px and on an iPhone 13 viewport: the three 2x2s, the 21-row and
  the 15-row tables, and an explanation table after an answer. The page never widens; a wide table
  scrolls inside itself.
- **Tests.** `tests/unit/rich-blocks.test.mjs` (9), `tests/e2e/question-tables.spec.js` (2),
  `npm run lint:data`.

## Not in this release

- 14 Epidemiology stems carry their data in the stem itself (a 2x2 in a sentence). Moving it to a
  table changes the stem, which is read aloud and, for three of them, already recorded. They follow
  once the read-aloud can keep saying the numbers.
- Lists and worked steps inside explanations.
