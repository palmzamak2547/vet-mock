## Reviewer notes

- The 35 entries were read a second time against their sources: 20 kept as written, 15 reworded, none removed.
- Three entries about the Australian prawn import risk analysis were cut down to what could be confirmed, because the
  2009 report could not be opened. They need that report re-read.
- 122 file-style names in older notes match no registered document, so they still print as a cleaned file name
  (extension dropped, underscores shown as spaces).
- Rules for the source line, in order: (1) a bracketed recording pointer becomes the label `sessionLabel` already
  gives elsewhere, with the minute ranges kept; the leading word "คลิป" is consumed with the id, so it is no longer
  printed twice. (2) A file name claimed by a document in `src/data/source-docs.js` shows that document's registered
  title, page reference kept. (3) Any other file-style name (`.pdf`, `.pptx`, `.docx`, or an underscored stem)
  loses the extension and shows underscores as spaces. Everything else is returned character for character.
- `humanSource` and `recordingMoments` share the same recording pattern, so the doubled "คลิป คลิป" is also gone
  from question source chips and the moment links.
- `noteSourceLabel(raw, titleFor)` takes the registry lookup from its caller. `source-docs.js` is 78 KB and uses
  regex lookbehind (not shipped, iOS 14), so `scripts/regen-note-source-titles.mjs` asks it once per file name the
  notes use and writes `src/data/note-source-titles.generated.js`; a unit test fails when that file is stale, and
  `regen:all` runs it.
- The VetWiki article page does not print `section.source`; it draws numbered source chips from
  `lib/vetwiki/cite.js`, so no second call site needed the change.
- Proof for the label change: `tests/unit/notes-source-label.test.mjs`.
- Release number: `release:new` gave 5.222.0. Open pull requests hold 5.217.0 (#231) and 5.217.3 (#234); the rest
  are dependency bumps. Nobody holds 5.222.0.
- Layout (Rule 11): nothing moved place; the source line gets shorter text, corrections use the existing component.
