# Release 5.223.0 — English MVP (โจทย์ zoonoses ฉบับอังกฤษ + ศัพท์ท้ายบท VetWiki)

Scope ที่รวมใน release นี้ (ผ่านการ grill กับเจ้าของ 3 รอบ + ตรวจเนื้อหา 2 รอบ 2026-11-14/15):

1. **ฉบับอังกฤษของโจทย์ zoonoses 367 ข้อ** — ไฟล์ข้อมูลคู่ขนาน
   `src/data/question-translations-zoonoses.js` (key ด้วย question id, options เรียง
   ตามลำดับเดิมของคลัง) · โหลดเป็น chunk `data-q-translations-zoonoses` เฉพาะเมื่อ
   นักเรียนกด EN · toggle ในแถบบนของหน้าทำโจทย์ (`vmx-lang-toggle`,
   preference `vmx-question-lang`) · ข้อที่ยังไม่มีฉบับแปลคงไทยพร้อมโน้ต ·
   เสียงอ่านยังอ่านฉบับไทย (คลิปอ่านออกเสียงเป็นคลังไทย)
2. **กล่อง "ศัพท์เฉพาะทางในบทนี้" ท้ายบท VetWiki** — `src/data/vetwiki-glossary-zoonoses.js`
   16 บท 213 คำ (chunk `data-vetwiki-glossary-zoonoses`) เรนเดอร์ใน WikiArticle
   ก่อน ChapterEnd เฉพาะบทที่มีข้อมูล
3. **แก้คลังตามหลักฐานภายนอก** — ข้อ 8031 ตัวเลือก E: ปีจาก พ.ศ. 2499 เป็น
   **พ.ศ. 2519 (ค.ศ. 1976)** หลักฐาน: "The first outbreak of duck plague in Thailand"
   *J Thai Vet Med Assoc* 1977;28:61-79 (อ้างใน Wiley "Duck Plague (Duck Virus
   Enteritis)" chapter, 2007) และ Dhama et al. 2017 *Vet Q* (Tamil Nadu, India,
   November 1976) — ไม่พบหลักฐานรองรับ พ.ศ. 2499 (1956) · ข้อ 106043 ตรวจแล้ว
   **ไม่แก้**: เฉลยค่ามัธยฐานสอดคล้องกับสิ่งที่บรรยาย Vet 85 สอน (mean + 2SD เป็น
   วิธีแบบ WHO/CDC ที่ต่างจากห้องเรียน)
