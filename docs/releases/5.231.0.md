# 5.231.0: review planner trimmed and in Thai, one meaning of "saved"

Wave 3 of the redesign (review tab), the slice that fits one release. The rest is listed at the end.

## What changed

- `src/views/SRSessionView.jsx` (planner and finished screen)
  - The start button reads `เริ่มทบทวน` (was `เริ่ม Session →`). `src/data/how-to.js` and the e2e and unit tests that
    press it use the new name; each still asserts the same thing.
  - The line under the planner's heading (`ทำติดต่อกันทุกวัน...`) is gone: nothing a student can act on.
  - The finished screen said "finished" twice (heading and a sentence); the sentence is gone. `ทำต่ออีก session →` is
    `ทำต่ออีกรอบ`.
  - Inside ปรับเอง the two coaching boxes lost their English words and long dashes (`Algorithm`, `review`), and the
    figures block and the notes moved from inline styles to `src/styles-review.css`. The `Due ทบทวน` reading that
    specs use stays where it was.
- `src/views/PinboardView.jsx`, `src/App.jsx` (one prop each way): the header's saved chip counts bookmarks, a
  different store from the pins the board lists, so the header could say 1 while the board said 0 (row O-249, traced:
  `HeaderBar.jsx` reads `bookmarks`, the board read `loadPins()`). The board now receives `bookmarks` and shows
  `ข้อที่บันทึกไว้ N ข้อ` with a button that opens the same practice set the header chip opens. The empty board says
  `ยังไม่มีรายการที่ปักหมุด` (it said "no saved items", the word the header uses for the other store).
- The planner's start button fix of 5.227.6 (`DecideLines`) and its checks are untouched.

## Decisions

- The two stores stay separate (merging bookmarks and pins touches sync and the shared store). The board names both
  instead, so the two numbers can no longer contradict each other.
- The back button beside start stays: the audit says the bar repeats it, but no route check was made on every
  viewport, and a student must never be stranded.

## Tests

- New `tests/unit/review-tab-saved-count.test.mjs`: the saved line (counts, zero and bad input), App passes the board
  the header's `bookmarks`, the planner's Thai wording.
- Updated for the new names: `sr-session-image-url`, `thai-copy-labels`, `pinboard-recovery`, the e2e specs that press
  the start button.
