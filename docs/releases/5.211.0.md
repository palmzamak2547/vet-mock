## How it was checked

- **The last reading.** All 148 proposed slides were drawn as the student sees them (51 sheets)
  and read by two independent checkers: 118 right, 29 weak, 1 with the key in doubt, none wrong.
- **A second reading of the close calls** the checkers listed. One `ok` was turned down:
  `equine-repro:105550` (the lines give only "shorten luteal phase / return to oestrus"; the
  cervix opening and the drainage the key names are not on them). Two keys that read "all of the
  above" were checked option by option against their slides by hand, because a sheet does not
  show the options: `milk-meat-hygiene:212044` and `:212057` hold. That gives 55 and 62.
- **By hand.** Three sheets (nine panels) of the Milk & Meat checker: all nine verdicts held.
- **Every page image answers.** A request for each cited page at the slide store returns an image:
  44 of 44 and 140 of 140.
- **In the app.** On the dev server at a phone's width, `equine-repro:105438` and
  `milk-meat-hygiene:212057` were opened and answered: the block "จากสไลด์ที่เรียน" shows the page
  image with its highlights (two and one) and the lines "Equine pregnancy and neonatal care หน้า 7"
  and "Egg hygiene: microbiology of the avian egg (slides) หน้า 15".
- `npm run lint:evidence`: 819 slides in 10 subjects, none waiting to be matched again.
  `tests/unit/answer-evidence.test.mjs`: 14 of 14. `npm run lint:data` passes. `npm run test:unit`:
  4,024 tests, 4,018 pass, 0 fail, 6 todo (the six are retrieval-quality cases marked weak on
  28 Oct). The e2e matrix runs in the pull request's CI.
