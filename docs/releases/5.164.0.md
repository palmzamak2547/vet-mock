# 5.164.0: a daily study reminder in the student's own calendar

VetMock has no push channel on the web, so the reminder is an event that repeats every day in the student's own
calendar (`src/lib/study-reminder.js`).

- **Where it is offered.** The result of the first set of a day asks once, ever, under the day count; any answer
  ("ไม่ต้อง" included) ends the offer. The connected-apps page keeps a reminder card for later.
- **The time.** Five times to pick from; with at least 3 sessions in the last 14 days, the median start of the
  student's own sessions is suggested first, rounded to the half hour (the day is cut at the widest gap, so a habit
  around midnight stays around midnight).
- **The calendar.** Google Calendar opens its own "new event" page filled in (daily, 15 minutes); any other calendar
  gets one .ics from `/api/calendar?study=HH:MM` (Apple, Outlook). One UTC instant repeated daily keeps the same Bangkok
  time all year. The copy says it reminds every day, even after a set, and how to stop it.
- **Inside the Android app** (`window.VetMockApp.notifications`) the offer asks the app instead: `status()` first,
  `request()` only on the student's tap, then `reminders.set({ enabled, minute })`; a "no" offers the phone's settings.
- The offer is its own chunk, fetched only when a first set of the day shows it, so the results view does not carry
  it (results JS 45,179 B gzip against its 46,500 B budget; statically imported it was 46,825 B, over).
