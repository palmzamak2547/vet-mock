# 5.153.0: connected apps

Owner ask (2026-10-21): one place to connect popular apps, fast, stable, real brand logos.
Owner picked Drive + Notion + calendar, Anki and Dropbox.

## What ships

- `ConnectAppsView` (view id `connect-apps`, no URL of its own, like the profile hub): reached
  from the profile hub ("เชื่อมแอป"), Account settings ("แอปที่เชื่อมไว้") and the palette.
  Grouped by what the student does: เอกสาร (Google Drive, Notion), ปฏิทิน, ทบทวน (Anki).
- Calendar: `GET /api/calendar?year=4|5` serves the exam timetable as iCalendar
  (`src/lib/exam-calendar.js`: Bangkok times as UTC instants, a reminder one day before, RFC 5545
  escaping and octet-safe folding for Thai). Buttons subscribe Google Calendar (cid=webcal),
  Apple Calendar (webcal://) and Outlook (addfromweb); CDN cache one hour.
- Anki: `src/lib/anki-export.js` writes Anki's text import (tab-separated, `#html:true`, Basic,
  deck `VetMock::<set>`, tags column) for pinned questions or questions still wrong; every
  graded type has a back, HTML is escaped. Imported on desktop Anki (File > Import), then synced.
- Documents: Drive and Notion cards appear only when the server can connect them (or the account
  already holds a grant): connect, open files (library external tab), disconnect.
- Logos: the brands' own marks from Wikimedia Commons in `public/brand/` (ATTRIBUTION.md), on a
  fixed white tile so the colours hold in dark mode; `<img>` files, no bundle cost.

## Not yet visible (owner steps)
