# 5.192.1: screens that broke silently work again, and say so when they cannot load

From a sweep of every screen for flows that failed without a word (7 Nov 2026, evening).

## How it was found

- A Playwright walk of every `/app/*` route on desktop (1280 px) and phone (390 px) at the real date, 7 Nov 2026 (the e2e suite pins 25 Sep, so date-bound screens of the final period are not seen there): no page errors, console errors or error boundaries on any route.
- Five read-only code audits, one per area (practice, the app shell, reading and library, accounts and social, the serverless functions), each finding traced to the line and checked by hand before a fix. 29 findings; 25 fixed here, 4 left with a reason (below).
- An independent review of the diff before merge. It found one regression (the rest page's back control labelled Home while it went to the rest page after leaving a set through Back), fixed in the second commit and walked in Chromium and WebKit.

## What shipped

- **Contribute screen** loads again: `ensureContributorRow` chained `.catch()` on a PostgREST builder, which has none (supabase-js 2.115.0), so every load threw before either read.
- **Review note editor** keeps notes up to 5,000 characters (it cut them to 500 and synced the cut).
- **Review of a short set** shows the filter tabs when more than one outcome exists, and every row keeps its number from the set.
- **Back out of a set**: the next Back is a real step, and an exam entry whose set is gone goes Home instead of an endless loading screen with no navigation. The set is parked at the moment of leaving, so a timed set's clock is not refunded.
- **"หมดเวลาข้อ N แล้ว"** shows only after the clock's own move.
- **Home's review plan** passes its count for one session (`vmx-sr-plan-size`, sessionStorage) and leaves the saved size alone.
- **VetWiki section links with Thai ids** scroll to the section after an in-app navigation (`location.hash` is decoded).
- **Said, with a retry, instead of an empty state**: wrap-ups (retry through `importFresh`), the library's in-document search, past reviews in the review queue, the passkey list, VetWiki article errors (in Thai), and a pinned question whose bank did not download.
- **PDF export in LINE/IG/FB browsers** uses the share sheet or says where to save, instead of "ส่งออกไฟล์แล้ว".
- **Feedback mail**: Resend bounded at 10 s (502 `mailer_unreachable`, logged `mailer_error`), a limiter outage no longer logged as `capped_burst`, the client gives up after 25 s. Handwriting: a limiter outage asks to try again, not "quota used up for today".
- **Race**: the question count types freely and clamps at use; start errors name the remedy.
- **Copy and access**: Thai labels on the group screens and the short-answer box; the note button no longer promises an (N) shortcut; the backup import is a real button and re-picks the same file.
