## vca.vetmock.com serves VCA material only

`vca/src/data/domains.js` now names what the site serves: the main bank's VCA subject, each question
matched by a row of `VCA_SOURCES` (a recalled round, a compilation of past papers, a set adapted from
one, the "VCA ผ่านชัวร์" set), or kept out by `NOT_VCA` with the reason /about prints. A VCA question
that no row names stops the build, so a new source is a decision, not a gap, and the next round's
recall needs a data change only.

| | Before | After |
|---|---|---|
| Questions on the site | 5,906 | 673 |
| Recalled VCA rounds | 123 | 236 |
| Adapted from the CUVET85 compilations | 121 | 121 |
| "VCA ผ่านชัวร์" | 316 | 316 |
| VetMock course questions (lecture, course papers, aligned) | 5,328 | 0, still in VetMock |
| Vet 80 faculty paper filed under the VCA subject | 18, shown as past papers | 0, explained on /about |

- A domain with no question is left off the site (no plate, page or draw); all 19 hold questions after
  this release.
- Answers students gave to course questions stay in their records and count nowhere
  (`vca/src/lib/progress.js`), so no meter passes 100% and a "missed" set holds only served questions.
- The unit and e2e tests that leaned on the old, course-fed sizes pick their domains by size from the
  bank; `domains.test.mjs` and `generated.test.mjs` pin the policy and its reconciliation.
