# 5.250.0: ส่วนเสริมที่โหลดไม่ขึ้นไม่ทำให้ทั้งหน้าว่าง และอ่านบัญชีไม่ได้ก็บอกตรงๆ

## สิ่งที่นิสิตเห็น

- **ส่วนของหน้าที่โหลดไม่ขึ้น:** ก่อนหน้านี้ การโหลดไฟล์ระดับ XP ที่หัวหน้าหลุดไปครั้งเดียว ทำให้ทั้งแอปเป็นหน้าว่าง
  (การกวาดหน้าจอวันที่ 16 พ.ย. เจอ 16 หน้า) และส่วนเสริมของหน้าแรก เช่น ภารกิจวันนี้ ทำให้ขึ้นการ์ด "หน้านี้ขัดข้อง"
  ตอนนี้ทุกส่วนที่โหลดทีหลังผ่าน `lazyWithRetry` (`src/lib/lazy-retry.js`): โหลดหลุดครั้งเดียว แอปขอไฟล์เดิมใหม่อีกครั้ง
  ส่วนเสริมอยู่ใน `OptionalFeature` ถ้ายังโหลดไม่ได้ ส่วนนั้นหายไป หน้าที่เหลือใช้ได้ และความผิดพลาดส่งเข้ารายงานข้อผิดพลาดเดิม
  ส่วนที่หน้าขาดไม่ได้ (ตัวหน้าเอง) ยังขึ้นการ์ดที่บอกตรงๆ พร้อมปุ่มโหลดใหม่ ไลบรารีฐานข้อมูลก็ขอใหม่หนึ่งครั้งเช่นกัน
- **อ่านบัญชีไม่ได้ (ฐานข้อมูลตอบ 500):** หน้าความคืบหน้าบนเครื่องที่ยังไม่เคยอ่านบัญชี เคยบอกว่า "ยังไม่มีความคืบหน้าให้ดู"
  ตอนนี้ขึ้น "ยังอ่านข้อมูลจากบัญชีไม่ได้" พร้อมปุ่มลองอีกครั้ง (`StatePanel` เดิม) หน้าแรกไม่ขึ้น "ใช้ VetMock ครั้งแรก?"
  หน้าว่างขึ้นเมื่อบัญชีว่างจริงเท่านั้น สัดส่วนคะแนนมากับแอป ไม่อ่านฐานข้อมูล แถบซิงก์ด้านบนบอกและมีปุ่มลองอีกครั้งอยู่แล้ว
- **หัวหน้าบนมือถือ:** ที่ 390 px เมื่อมีข้อที่บันทึกไว้ ปุ่มช่วงสอบเคยถูกปุ่มค้นหาทับ 22 x 44 px แตะแล้วเปิดการค้นหา
  ตอนนี้กลุ่มปุ่มย่อลงได้ และเมื่อมีปุ่มข้อที่บันทึกไว้ที่ความกว้างไม่เกิน 430 px โลโก้หลบให้ (แถบล่างมีหน้าแรกอยู่แล้ว)

## ตัวกัน

`tests/unit/lazy-guard.test.mjs` ไม่ยอมให้มี `lazy()` ตรงๆ ที่ไหนใน `src/` นอกจากตัวช่วย
รายการยกเว้นมีสองไฟล์ในขั้นตอนดูผลสอบ (`ResultsView.jsx`, `ReviewView.jsx`) ซึ่งงานนี้ไม่แตะ รายการนี้ลดได้อย่างเดียว

## ตรวจอย่างไร

- `tests/e2e/optional-feature-failure.spec.js` (Chromium และ Firefox): ตัด XpChip ทุกครั้ง หน้ายังพิมพ์และเปิดค้นหาได้
  ตัดภารกิจวันนี้ครั้งแรกครั้งเดียว แอปขอใหม่และภารกิจขึ้น ตัดทุกครั้ง หน้าแรกยังอยู่ไม่มีการ์ดขัดข้อง
- `tests/e2e/database-failure.spec.js` (bundle ที่ต่อฐานข้อมูล, Chromium มือถือและเดสก์ท็อป, รัน 3 รอบผ่านทั้งหมด):
  ฐานข้อมูลตอบ 500 บนหน้าแรก ความคืบหน้า และสัดส่วนคะแนน แล้วกลับมาตอบปกติหลังกดลองอีกครั้ง
- กวาดหน้าจอ `npm run sweep:defects` 32 หน้าที่ 390 x 664 สว่าง: ปุ่มหัวหน้าทับกัน 0 (เดิม 78 แถวใน 20 หน้า)
