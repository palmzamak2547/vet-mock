# 5.275.0: สมุดที่เบราว์เซอร์ไม่ยอมเก็บ แอปบอกทันทีตอนเพิ่มหน้าหรือเปิดสมุด

## สิ่งที่นิสิตเห็น

- **เพิ่มหน้ากระดาษในสมุด:** ถ้าเบราว์เซอร์ไม่ยอมเก็บจำนวนหน้าใหม่ (พื้นที่เต็มหรือปิดการเก็บข้อมูลไว้)
  ก่อนหน้านี้หน้าใหม่ยังขึ้นมาเหมือนบันทึกแล้ว แต่หายไปเมื่อเปิดสมุดครั้งหน้า พร้อมสิ่งที่เขียนบนหน้านั้น
  ตอนนี้ขึ้นกล่อง "บันทึกไม่สำเร็จ" กล่องเดียวกับที่ชั้นสมุดใช้ตอนสร้างหรือลบสมุด (5.239.0) บอกวิธีแก้ และไม่เพิ่มหน้าที่เก็บไม่ได้
- **เปิดสมุด:** ถ้าเบราว์เซอร์ไม่ยอมเก็บ สมุดยังเปิดได้ และขึ้นกล่องเดียวกัน ให้รู้ก่อนเริ่มเขียน

## สิ่งที่เจ้าของเห็น

- รายการไฟล์ล่าสุดในหน้าเขียนบน PDF ที่อ่านไม่ได้ และการย้ายรอยเขียนจากที่เก็บแบบเก่าที่ไม่สำเร็จ
  นับผ่าน `reportFailure` เข้าการ์ด "ล้มเหลวใน 24 ชั่วโมง" ใน `/app/admin` (นับครั้งเดียวต่อการโหลดหน้า)
  นิสิตไม่เห็นอะไรเพิ่ม การย้ายข้อมูลยังทำเหมือนเดิม คีย์เก่าไม่ถูกลบ

## ตรวจอย่างไร

- `tests/unit/pdf-notes-failures-said.test.mjs` รันโค้ดจริงของหน้าเขียนบน PDF: เพิ่มหน้าเมื่อเก็บไม่ได้ขึ้นกล่องและไม่เปิดหน้าใหม่,
  เพิ่มหน้าเมื่อเก็บได้ไม่ขึ้นอะไร, เปิดสมุดเมื่อเก็บไม่ได้ขึ้นกล่องและยังเปิด, รายการล่าสุดอ่านไม่ได้ถูกนับเป็น `load`,
  การย้ายรอยเขียนแบบเก่าที่เขียนไม่ได้ถูกนับครั้งเดียวเป็น `save` พร้อมเหตุผล บนโค้ดก่อนแก้ 4 ใน 5 ข้อไม่ผ่าน
- ภาพกล่องที่ 390 x 664 และ 1280 สว่างและมืด
