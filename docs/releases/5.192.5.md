# 5.192.5: search finds pasted Thai and whole names; daily question and Pomodoro keep the right day; VCA grades on today's key

## What shipped

The last batch of the subsystem sweep that also produced 5.192.3 and 5.192.4: two independent reviews per finding,
a test seen failing first, each lane's diff read again before it was picked.

1. **Search** (`src/lib/thai-search.js`, `omni-intents.js`, `omni-ask.js`, `vetwiki/runtime-search.js`): PDF search
   finds น้ำ / ต่ำ when NIKHAHIT comes before the tone mark; the study card matches a course by its Thai name (names
   lower-cased, looked for in the query as typed, a Latin end must end its word); the offline nearest-articles fallback
   reads Latin alias forms with `latinPattern`; the dose card needs a drug name to start a word; VetWiki full-text
   search also tries the folded query; โล parses as a weight unit after a Thai letter. `eval:vetwiki` byte-identical
   before and after (hit@5 100%, MRR@10 0.923).
2. **Daily question and Pomodoro** (`src/lib/daily-q.js`, `src/lib/pomodoro.js`, `HomeView.jsx` DailyQRow,
   `TodaysQModal.jsx`, `PomodoroTimer.jsx`, `PomodoroView.jsx`): Home left open overnight shows the new day's question
   and files an answer under the day its question was shown for; a focus that ended while away is logged at its end
   time; the 200-row cap drops failed rows first and keeps dropped study days as one run, so a long streak survives
   it; the 7-day count steps calendar days across daylight saving.
3. **VetMock VCA** (`vca/src/online/account.js`, `vca/src/pages/Session.jsx`, `vca/src/lib/start.js`): only the newest
   `follow()` writes, so the first-sign-in profile sheet stays open and a sign-out wins; a mock that lapsed while closed
   is graded once the bank is read; answer keys work only on a question on screen; "retry missed" survives a stale
   domain id. VCA suite 364/364 (354 before).
4. The 5.192.4 release record.

Checks before merge: 18 search, omni, VetWiki-runtime, daily-q, Pomodoro and Home test files, 180/180 under
Asia/Bangkok, UTC and America/Los_Angeles; `lint:changelog-latest`, `changelog-voice`, `lint:ui-copy`.
