# 5.172.2: the printable timetable survives an offline tap, and Home names the registrar window closing first

An independent review of 5.167.0 found nine defects. This release fixes them, plus three more of the same kind.

What a student notices:
- **Offline tap.** Tapping **ดาวน์โหลดตารางสอบ** without a connection no longer replaces the schedule page with the error card.
  - The exam cards stay, and a note says why.
  - **ลองอีกครั้ง** opens the sheet once it can load. A second failure while online also offers **โหลดหน้านี้ใหม่**.
  - The sheet's code is also loaded while the page is idle, but never offline or on Save-Data.
- **Home chip.** Home's registrar chip names the open window that closes first, in a short name of its own. On 28 Oct it read "แสดงความจำนง รอบ 1 ภาคปลาย, เหลือ 11 วัน" instead of the payment window, cut short.
- **Bangkok days.** Registrar windows and calendar events count Bangkok days, so a phone set to another time zone no longer counts each window a day off.
- **Same-day papers.** Two papers on one day are listed in the order they are sat, on the page and on the sheet.
- **Course-group box.** It names the term its code registers (ภาคการศึกษาต้น 2569).

The printed page:
- A paper without a `term` joins the period it falls in.
- A compact layout fits up to 16 papers. Past that, the layout check reports "tight" instead of letting rows cross the notes.
- Course names and rooms are bounded by the items beside them. A long one drops the duration first, then is cut with an ellipsis.
- At 1.25x, the page is painted to its last row and column of pixels.
- Closing the sheet mid-draw leaves no object URL behind, and every canvas is emptied after use.
- A paper whose time does not parse counts as over at the end of its day, not at 11:00.

## Checks

- Offline PDF download. The PDF library is not preloaded, so saving the image works offline, but the PDF may not.
