# 5.158.0: text notes on the page (writing studio 3)

Third slice of the writing studio, PR #56, merged as `7dcf415f`.

- Text tool: tap the page to type; tapping away or Ctrl/Cmd+Enter saves, Esc cancels, tapping a note edits it.
- A note is a stroke (`mode: 'text'`): it syncs, tombstones, undoes and moves, resizes and recolours with the lasso.
  It is painted into the ink canvas, so exports carry it. Thai wraps on word boundaries (`Intl.Segmenter`).
- Editing replaces the note under a new id; one undo restores the old text.
