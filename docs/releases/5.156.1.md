# 5.156.1: blank notebooks open on production

Hotfix for 5.156.0, PR #54, merged as `443b06af`.

- A document the app made itself is handed to the reader as bytes (`ingestRemote({ bytes })`,
  `pdfjs.getDocument({ data })`), so no `blob:` URL is fetched and the production CSP needs no change.
- The notebook e2e runs under the CSP read from `vercel.json` (minus `upgrade-insecure-requests`) and fails on any CSP
  refusal; it failed against 5.156.0's reader and passed with the fix.
