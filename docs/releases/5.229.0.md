# 5.229.0: a wording check, and the first pass over interface text

What a student notices: messages and labels on About, sign-in errors, the drug calculator, the screening bench and
the lab page read as sentences a person wrote. The long dash between clauses became a colon or a space; meaning,
numbers, doses and terms did not change.

What it contains:

- `scripts/lint-voice.mjs` (`npm run lint:voice`, in `lint:data`): reads only what a person sees (strings and JSX
  text in screens, the text fields of notes, wrap-ups and question banks, the changelog and how-to, the prose of
  `README.md` and `docs/*.md`), never a comment or a generated file. Patterns, with the reason and the rewrite, are
  in `scripts/voice-patterns.json`; counts are in `docs/voice-budget.json` and may only fall. `--list` prints every
  finding with file and line. Extractor: `scripts/lib/voice-text.mjs`. Tests: `tests/unit/lint-voice.test.mjs`.
- Fix pass 1, interface text only, in files that no open branch changes (the others are listed in
  `work/language-voice/report.md` with their findings).

Not included: fix pass 2 for notes, wrap-ups and question banks (`scripts/fix-voice.mjs`), the terms report, and
the interface files that open branches change.
