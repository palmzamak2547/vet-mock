## Google Drive and Notion connect (built, not yet visible)

`drive.readonly` is a restricted scope: without Google's security assessment it cannot serve the
cohort. The connection now asks for `drive.file` and the library's external tab gains a Google
Picker ("เลือกไฟล์จาก Google Drive"); `/api/list-external-files?provider=google&picker=1` hands
the picker the student's own short-lived token, the app id (the project number every OAuth
client id starts with) and `GOOGLE_PICKER_API_KEY`. CSP allows `https://apis.google.com`
(script) and `https://docs.google.com` (frame).

Server side done 2026-10-21: `public.external_connections` did not exist in production; migration
20261007150000 applied (RLS on, no policy; an anon REST select returns `[]`).
`SUPABASE_SERVICE_ROLE_KEY` and `EXTERNAL_OAUTH_STATE_SECRET` added to Vercel production.

The connect buttons stay hidden (`/api/external-connect` answers `{"google":false,"notion":false}`)
until the owner-account steps below are done.
