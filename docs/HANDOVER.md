# ถ้าไม่มีคนดูแล VetMock

VetMock ออกแบบให้รันเองได้ยาว ๆ โดยไม่ส่งต่อภาระให้ใคร หน้านี้บอกสามเรื่อง อะไรเดินเองได้
อะไรหยุดได้และหยุดแบบไหน และถ้ามีคนอยากช่วย จะดูจากตรงไหน ไม่มีอะไรในนี้ที่ต้องทำทุกวัน

เขียน 29 ต.ค. 2569 จากการตรวจระบบจริง วันที่และตัวเลขในนี้คือวันที่ตรวจ หน้าแอดมินบอกค่าปัจจุบัน

## สิ่งที่เดินเองได้

| ส่วน | ทำไมเดินเองได้ |
|---|---|
| ฝึกโจทย์ สอบจำลอง ทบทวน | โจทย์อยู่ในตัวแอป ไม่ต้องพึ่งบริการภายนอก ใช้ได้โดยไม่ต้องเข้าสู่ระบบ และส่วนที่เคยเปิดแล้วเปิดออฟไลน์ได้ |
| ชีทสรุป VetWiki | อยู่ในตัวแอปเหมือนกัน |
| คลังเอกสาร | ไฟล์อยู่ที่ Cloudflare R2 รายการอยู่ที่ Supabase ทั้งสองไม่ต้องมีคนเปิด |
| Supabase แผน Free | หยุดโปรเจกต์ที่ไม่มีใครใช้ราว 7 วัน จึงมี cron ใน `vercel.json` เรียก `/api/ai-chat?warm=1` วันละครั้ง (ค้นคลังเอกสารหนึ่งครั้ง) Supabase เป็นคนกำหนดว่าอะไรนับเป็นการใช้งาน วิธีนี้ใช้กันทั่วไปแต่ไม่มีใครรับประกัน |
| เสียงอ่าน | ถ้าเสียงคุณภาพสูงใช้ไม่ได้ แอปอ่านด้วยเสียงของเครื่องเอง |
| VetMock AI | ลอง DeepSeek ก่อน แล้ว Anthropic ถ้าผู้ให้บริการแรกล่ม |

## สิ่งที่หยุดได้ ถ้าไม่มีใครจ่ายหรือต่ออายุ

เรียงจากกระทบมากไปน้อย คอลัมน์สุดท้ายคือสิ่งที่นิสิตเห็น

| เหตุการณ์ | หยุดอะไร | นิสิตเห็นอะไร |
|---|---|---|
| โดเมน vetmock.com หมดอายุ (25 ก.ย. 2570) | ทุกเว็บ | เข้าเว็บไม่ได้ |
| บัตรของ Vercel หมดหรือชนเพดานค่าใช้จ่าย | ทุกเว็บ | เข้าเว็บไม่ได้ |
| Supabase ถูกหยุด หรือเต็ม 500 MB | เข้าสู่ระบบ ซิงก์ คลังเอกสาร แหล่งอ้างอิงจากคลังของ AI | ฝึกโจทย์และอ่านชีทได้ แต่บันทึกเข้าบัญชีไม่ได้ |
| Upstash หยุด | API ที่จำกัดจำนวน (เสียงอ่านจากเซิร์ฟเวอร์ AI แจ้งปัญหา ผลสอบ) ตอบ 503 | ฟีเจอร์นั้นใช้ทางสำรองหรือบอกว่าใช้ไม่ได้ ฝึกโจทย์ได้ตามเดิม |
| เครดิต AI หมดทั้งสองเจ้า | VetMock AI | AI บอกว่าตอบไม่ได้ |
| token ของ Cloudflare หมดอายุ | เปิดไฟล์ในคลังเอกสาร | เปิดไฟล์ไม่ได้ |
| Microsoft เปลี่ยนระบบเสียงอีก | เสียงคุณภาพสูง | ได้เสียงของเครื่องแทน |
| ไม่มีใครใส่ตารางสอบเทอมใหม่ | การแยกกลางภาคและปลายภาค | กฎของ Palm คือไม่กรองเลยเมื่อไม่มีตาราง และบอกตรง ๆ |
| dependency มีช่องโหว่ | ไม่มีอะไรอัปเดตเอง | ไม่เห็นอะไร |

## ดูจากตรงไหนว่ามีอะไรหยุด

เข้าสู่ระบบด้วยบัญชีผู้ดูแล แล้วเปิด https://vetmock.com/app/admin

- **ระบบภายนอก** (บนสุด) ตรวจสดทุกครั้งที่เปิดหน้า ทุกแถวมีช่อง "ต้องทำอะไร" และลิงก์มาที่หัวข้อด้านล่าง
  "ปกติ" คือใช้ได้ "ควรดู" คือใกล้หมดอายุ "ใช้ไม่ได้" คือฟีเจอร์นั้นกำลังใช้ทางสำรอง "ปิดอยู่" คือยังไม่ได้ตั้งค่า
- **ระบบแจ้งปัญหา** สิ่งที่นิสิตแจ้งเข้ามา
- **ข้อผิดพลาดฝั่งผู้ใช้** นับเฉพาะเครื่องที่อนุญาต analytics ศูนย์จึงไม่ได้แปลว่าไม่มีปัญหา
  (ระบบนี้ตรวจแล้วว่าใช้ได้ทั้งสาย เมื่อ 28 ต.ค. 2569)
- ตัวเลขผู้ใช้นับเฉพาะคนที่เข้าสู่ระบบ

บัญชีอื่นเปิดหน้านี้จะไม่ได้ข้อมูลอะไร เพราะฐานข้อมูลเป็นคนตรวจสิทธิ์ ผู้ดูแลคือแถวในตาราง `public.admin_users`

## วิธีแก้แต่ละแถวของการ์ดระบบภายนอก

คีย์ทุกตัวอยู่ใน Vercel (โปรเจกต์ `vetmock`, Settings, Environment Variables) แก้แล้วต้อง Redeploy
หนึ่งครั้งค่าใหม่จึงมีผล ห้ามใส่คีย์ลงใน GitHub เพราะ repo นี้เป็นสาธารณะ

<a id="voice"></a>
### เสียงอ่านโจทย์
Microsoft Edge เป็นบริการฟรีที่ไม่มีสัญญา ใช้ผ่านไลบรารี `msedge-tts` ถ้าพัง ให้อัปเดตไลบรารีเป็นรุ่นล่าสุด
(21 ถึง 28 ต.ค. 2569 พังเพราะ Microsoft เปลี่ยนวิธียืนยันตัว แก้ด้วยรุ่น 2.1.1) เสียงไทยของ Edge มีสองเสียง
เลือกที่ `VOICE_MAP` ใน `api/tts.js` iApp ให้เสียงไทยอีกแบบ ใช้เครดิต (เติมที่ iapp.co.th) ไม่จำเป็นถ้า Edge ใช้ได้

<a id="mic"></a>
### ไมค์ของ VetMock AI
Chrome Edge และ Safari ใช้ไมค์ของเบราว์เซอร์เอง Firefox และเบราว์เซอร์ในแอป เช่น LINE ต้องถอดเสียงที่เซิร์ฟเวอร์
ทางที่ถูกที่สุดคือ token ของ Cloudflare ที่มีสิทธิ์ Workers AI ใส่เป็น `CF_AI_TOKEN` (ฟรีในโควตารายวัน)

<a id="ai"></a>
### VetMock AI
การ์ดบอกยอดเงิน DeepSeek ได้ตรง ๆ ส่วน Anthropic บอกได้แค่ว่าคีย์ใช้ได้ ยอดเครดิตดูที่ console.anthropic.com
เสียง Mochi แบบสด (Gemini) ยังเปิดเฉพาะผู้ดูแล

<a id="quota"></a>
### ตัวนับโควตา (Upstash)
ถ้า Upstash ใช้ไม่ได้ ระบบเลือกปฏิเสธ (ตอบ 503) แทนปล่อยผ่าน เพื่อกันค่าใช้จ่ายบานปลาย ตรวจบัญชีที่ upstash.com
และค่า `UPSTASH_REDIS_REST_URL` กับ `UPSTASH_REDIS_REST_TOKEN`

<a id="library"></a>
### คลังเอกสาร (Cloudflare R2)
ไฟล์เปิดผ่าน `CLOUDFLARE_API_TOKEN` การ์ดเตือนก่อนหมดอายุ 30 วัน สร้าง token ใหม่ที่ dash.cloudflare.com
(สิทธิ์ R2 ของ account นี้) ลิงก์ไฟล์ที่ออกไปแล้วจะใช้ไม่ได้ นิสิตกดเปิดใหม่ก็ได้ลิงก์ใหม่

<a id="signing"></a>
### กุญแจเซ็นผลสอบ
`VETMOCK_RPC_SIGNING_KEY` ใน Vercel ต้องตรงกับแถว `app-rpc` ในตาราง `private.application_signing_keys`
ของ Supabase เปลี่ยนต้องเปลี่ยนสองที่พร้อมกัน (`docs/data-durability-and-operations.md`)

<a id="email"></a>
### อีเมลแจ้งปัญหา
ส่งผ่าน Resend ไปที่ `FEEDBACK_EMAIL` ถ้าไม่ได้ตั้งจะไปที่ Gmail ของ Palm ผู้ส่งตอนนี้เป็นที่อยู่ทดสอบของ Resend
ซึ่งส่งได้เฉพาะอีเมลของเจ้าของบัญชี Resend ถ้าจะให้ไปถึงคนอื่น ยืนยันโดเมน vetmock.com ใน Resend
(เพิ่ม DNS record ที่ Cloudflare) แล้วตั้ง `FEEDBACK_FROM` เช่น `VetMock <feedback@vetmock.com>`

<a id="connectors"></a>
### เชื่อม Google Drive และ Notion
ปุ่มซ่อนอยู่จนกว่าจะมี OAuth client (`GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`,
`GOOGLE_PICKER_API_KEY`, `NOTION_OAUTH_CLIENT_ID`, `NOTION_OAUTH_CLIENT_SECRET`) และ
`EXTERNAL_OAUTH_STATE_SECRET` เอกสาร Google ที่เปิดสาธารณะยังเปิดได้โดยไม่ต้องเชื่อม

<a id="domain"></a>
### โดเมน vetmock.com
จดกับ Cloudflare Registrar หมดอายุ 25 ก.ย. 2570 ต่ออายุอัตโนมัติถ้าบัตรในบัญชียังใช้ได้ การ์ดเตือนก่อน 60 วัน
DNSSEC เปิดแล้ว

<a id="supabase"></a>
### Supabase หยุดโปรเจกต์
เจ้าของบัญชีกด Restore ได้ที่ supabase.com/dashboard อีเมลเตือนก่อนหยุดไปที่เจ้าของบัญชี วิธีที่แน่นอนกว่าคือแผน Pro

## ถ้ามีคนอยากช่วย (ไม่บังคับ)

**ต้นเทอม** (ก.ค. และ ธ.ค.) ตอนนี้ต้องใช้คนที่แก้โค้ดได้ เพราะ test ตรึงข้อมูลเทอมไว้
1. `src/data/semester.js` ใส่ `SEMESTER` ของเทอมใหม่
2. `src/data/schedule.js` ใส่วิชาที่สอบ ทุกแถวของเทอมใหม่ต้องมี `term` (`midterm` หรือ `final`)
   และเอา `term` ออกจากแถวของเทอมเก่า แล้วรัน `npm run regen:exam-papers`
3. `src/data/curriculum.js` บอกว่าแต่ละหัวข้อออกกลางภาคหรือปลายภาค (`examScope`) จากเค้าโครงรายวิชาของปีนี้
   (AGENTS.md กฎข้อ 10)
4. การ์ด Panic ชุดข้อตามผู้สอน และสรุปก่อนสอบ ทำใหม่หรือเอาของเก่าออกในการแก้ครั้งเดียวกัน
5. เลื่อนวันที่ที่ test ตรึงไว้ (`tests/e2e/fixtures.js` ค่า `PINNED_NOW` และ unit test ที่อ้างเทอมเก่า)
6. `npm run regen:all` แล้ว `npm run release:new -- patch` เปิด pull request แล้วรอ CI

**สิงหาคม** ตัดสินว่าปีปัจจุบันของแอปคือชั้นปีไหน (`CURRENT_YEAR` และ `YEARS` ใน `src/data/curriculum.js`
มีผลกับคนที่เข้ามาครั้งแรกเท่านั้น) และข้อความที่ระบุรุ่น (`curriculum.js`, `src/components/Wordmark.jsx`,
`src/data/videos.js`)

**ดึงสไลด์ใหม่จาก MyCourseVille** สคริปต์อยู่ในโฟลเดอร์ `.mcv/` บนเครื่องของ Palm ไม่ได้อยู่ใน GitHub
และต้องใช้บัญชีของนิสิตที่ยังเรียนอยู่ ลำดับอยู่ใน AGENTS.md หัวข้อ durable rules

**ถ้าจะรับดูแลต่อ** เพิ่มเป็น collaborator ระดับ Admin ของ GitHub `palmzamak2547/vet-mock`, เชิญเข้าทีม Vercel
organization Supabase และ account Cloudflare แล้วย้ายบัตรที่จ่ายค่า Vercel และค่าโดเมน เพิ่มบัญชีผู้ดูแลใน
Supabase (SQL Editor หลังคนใหม่เข้าสู่ระบบ vetmock.com หนึ่งครั้ง)
```sql
insert into public.admin_users (user_id)
select id from auth.users where email = 'อีเมลของคนใหม่';
```

**คนที่แก้โค้ด** อ่าน `AGENTS.md` ก่อน ทุกการแก้เป็น pull request และ CI คือด่านตรวจ merge แล้วดู CI ของ `main`
และ Vercel จนเสร็จ แล้วเปิดเว็บจริงดูสิ่งที่แก้
