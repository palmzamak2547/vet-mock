# คู่มือส่งต่อ VetMock

เขียนให้ผู้ดูแลคนถัดไปที่ไม่ได้เป็นนักพัฒนา งานส่วนใหญ่ในนี้ทำได้จากหน้าเว็บของแต่ละบริการ
และแก้ไฟล์ข้อมูลไม่กี่ไฟล์ ส่วนที่ต้องเขียนโค้ดจะบอกไว้ตรง ๆ

เขียนครั้งแรก 29 ต.ค. 2569 จากการตรวจระบบจริงในคืนนั้น ตัวเลขและวันที่ในนี้คือวันที่ตรวจ
ไม่ใช่ค่าปัจจุบัน ให้เชื่อหน้าแอดมินมากกว่าเอกสารนี้

## ถ้าจำได้อย่างเดียว

1. เข้าสู่ระบบด้วยบัญชีผู้ดูแล แล้วเปิด https://vetmock.com/app/admin เดือนละครั้ง
2. ดูการ์ด **ระบบภายนอก** ด้านบนสุด แถวไหนไม่ใช่ "ปกติ" ให้ทำตามช่อง "ต้องทำอะไร" ของแถวนั้น
3. ดูการ์ด **ระบบแจ้งปัญหา** ว่านิสิตแจ้งอะไรเข้ามา

แอปออกแบบให้นิสิตใช้ต่อได้เมื่อบริการภายนอกล่ม เช่น เสียงอ่านเปลี่ยนเป็นเสียงของเครื่อง
ปุ่มไมค์หายไป ปุ่มเชื่อม Drive ซ่อนอยู่ ซึ่งดีสำหรับนิสิต แต่แปลว่า **ไม่มีใครเห็นว่าอะไรพัง
นอกจากหน้าแอดมิน**

## 3. ดูจากหน้าแอดมินว่ามีอะไรต้องทำ

เปิด https://vetmock.com/app/admin หลังเข้าสู่ระบบด้วยบัญชีผู้ดูแล บัญชีอื่นเปิดแล้วจะเห็น
"หน้านี้เปิดให้เฉพาะผู้ดูแล" และไม่ได้ข้อมูลอะไรเลย เพราะฐานข้อมูลเป็นคนตรวจสิทธิ์

| การ์ด | อ่านยังไง |
|---|---|
| **ระบบภายนอก** | ตรวจสดทุกครั้งที่เปิดหน้า "ปกติ" คือใช้ได้ "ควรดู" คือใกล้หมดอายุหรืออ่านค่าไม่ได้ "ใช้ไม่ได้" คือฟีเจอร์นั้นกำลังใช้ทางสำรองหรือหายไปจากหน้าจอนิสิต "ปิดอยู่" คือยังไม่ได้ตั้งค่า ลิงก์ "วิธีทำ" พามาที่หัวข้อของบริการนั้นในเอกสารนี้ |
| **ระบบแจ้งปัญหา** | จำนวนรายงานจากหน้าแจ้งปัญหา ธงบนข้อสอบ และกล่อง VetWiki ตัวข้อความไปที่อีเมลใน `FEEDBACK_EMAIL` |
| **โจทย์ที่คนผิดบ่อย** | ข้อที่ควรเช็กเฉลย เริ่มจากข้อที่มีธง |
| **ข้อผิดพลาดฝั่งผู้ใช้** | นับเฉพาะเครื่องที่นิสิตกดอนุญาต analytics ไว้ (หน้าความเป็นส่วนตัวสัญญาไว้แบบนั้น) **ศูนย์ไม่ได้แปลว่าไม่มีปัญหา** ระบบนี้ตรวจแล้วว่าใช้ได้ทั้งสาย เมื่อ 28 ต.ค. 2569 |
| **ตัวเลขผู้ใช้** | นับเฉพาะคนที่เข้าสู่ระบบ คนที่ใช้โดยไม่ล็อกอินไม่ถูกนับที่ไหนเลย |

## 6. ดึงสไลด์จาก MyCourseVille

ขั้นตอนอยู่ใน AGENTS.md หัวข้อ durable rules: `.mcv/dump-current.py` แล้ว `.mcv/diff-current.mjs`
แล้ว `scripts/ingest-library.mjs` จากนั้น `python -I scripts/library-pages.py extract` และ `load`
เพื่อให้ค้นในเนื้อหาเอกสารได้และให้ AI อ้างอิงได้

**ข้อควรรู้:** สคริปต์ในโฟลเดอร์ `.mcv/` ไม่ได้อยู่ใน GitHub (อยู่ในเครื่องของ Palm) และต้องใช้
บัญชี MyCourseVille ของนิสิตที่ยังเรียนอยู่ (`MCV_USERNAME`, `MCV_PASSWORD` ในไฟล์ `.env`
ของเครื่องนั้น) ผู้ดูแลคนใหม่ต้องได้สคริปต์ชุดนี้จาก Palm โดยตรง และใช้บัญชีของตัวเอง
เอกสารที่มีชื่อหรือเลขประจำตัวนิสิตจะถูกกันไว้ไม่เก็บข้อความ ให้คนตัดสินว่าจะทำอะไรกับไฟล์นั้น

## 7. วิธีแก้ตามแถวในการ์ดระบบภายนอก

ทุกครั้งที่แก้คีย์ใน Vercel (Project `vetmock`, Settings, Environment Variables) ต้อง
**Redeploy** โปรเจกต์ครั้งหนึ่งค่าใหม่จึงมีผล ถ้าไม่อยาก redeploy เอง ให้รอ merge ครั้งถัดไป

<a id="voice"></a>
### เสียงอ่านโจทย์

- **Microsoft Edge** เป็นบริการฟรีที่ไม่มีสัญญา ใช้ผ่านไลบรารี `msedge-tts` เคยพังตั้งแต่
  21 ต.ค. 2569 เพราะ Microsoft เปลี่ยนวิธียืนยันตัว และกลับมาใช้ได้เมื่ออัปเดตไลบรารีเป็น 2.1.1
  (28 ต.ค.) ถ้าพังอีก ให้คนที่เขียนโค้ดได้อัปเดต `msedge-tts` เป็นรุ่นล่าสุด ระหว่างนั้นนิสิต
  ได้ยินเสียงของเครื่องแทน
- **iApp** ให้เสียงภาษาไทยที่ดีกว่า ใช้เครดิต เติมที่ iapp.co.th วันที่ตรวจ (28 ต.ค.) เครดิตเป็น 0
  ไม่เติมก็ได้ถ้า Edge ใช้ได้
- คลิปเสียงที่สร้างไว้ล่วงหน้า (tts.vetmock.com) มีเฉพาะวิชาอายุรศาสตร์สัตว์ปีก สร้างเพิ่มด้วย
  `node scripts/tts-clips.mjs --subject <id>` ซึ่งใช้เครดิต OpenRouter หรือ Gemini

<a id="mic"></a>
### ไมค์ของ VetMock AI

Chrome Edge และ Safari ใช้ไมค์ของเบราว์เซอร์เอง ส่วน Firefox และเบราว์เซอร์ในแอป เช่น LINE
ต้องส่งเสียงมาถอดที่เซิร์ฟเวอร์ ถ้าถอดไม่ได้ ปุ่มไมค์จะไม่แสดงในเบราว์เซอร์เหล่านั้น
ทางที่ถูกที่สุดคือสร้าง API token ของ Cloudflare ที่มีสิทธิ์ **Workers AI** แล้วใส่ใน Vercel
ชื่อ `CF_AI_TOKEN` (ใช้ฟรีในโควตารายวัน) อีกทางคือเติมเครดิต iApp

<a id="ai"></a>
### VetMock AI

AI ลองผู้ให้บริการตามลำดับ DeepSeek ก่อน แล้ว Anthropic ถ้าหมดทั้งสองเจ้า AI จะตอบไม่ได้
การ์ดบอกยอดเงิน DeepSeek ได้ตรง ๆ ส่วน Anthropic บอกได้แค่ว่าคีย์ใช้ได้ ยอดเครดิตต้องดูที่
console.anthropic.com เอง

เสียง Mochi แบบสด (Gemini) ยังเปิดเฉพาะบัญชีผู้ดูแล ไม่มีผลกับนิสิต

<a id="quota"></a>
### ตัวนับโควตา (Upstash)

API ทุกตัวที่จำกัดจำนวนครั้งต่อคน นับผ่าน Upstash ถ้า Upstash ใช้ไม่ได้ ระบบเลือก **ปฏิเสธ**
(ตอบ 503) แทนการปล่อยผ่าน เพื่อไม่ให้ค่าใช้จ่ายบานปลาย ผลคือเสียงอ่าน AI แจ้งปัญหา และผลสอบ
หยุดพร้อมกัน ตรวจบัญชีที่ upstash.com และค่า `UPSTASH_REDIS_REST_URL` กับ
`UPSTASH_REDIS_REST_TOKEN` ใน Vercel

<a id="library"></a>
### คลังเอกสาร (Cloudflare R2)

ไฟล์ในคลังเอกสารเปิดผ่าน `CLOUDFLARE_API_TOKEN` ถ้า token หมดอายุหรือถูกลบ นิสิตจะเปิดไฟล์
ไม่ได้ การ์ดเตือนก่อนหมดอายุ 30 วัน สร้าง token ใหม่ที่ dash.cloudflare.com (สิทธิ์ R2 อ่านเขียน
ของ account นี้) แล้วแก้ใน Vercel หลังเปลี่ยน token ลิงก์ไฟล์ที่ออกไปก่อนหน้าจะใช้ไม่ได้
(ปกติลิงก์มีอายุไม่กี่นาทีอยู่แล้ว) นิสิตกดเปิดไฟล์ใหม่ก็ได้ลิงก์ใหม่

<a id="signing"></a>
### กุญแจเซ็นผลสอบ

ผลสอบ ห้องแข่ง และรายงานข้อผิดพลาด ต้องเซ็นด้วยกุญแจ `VETMOCK_RPC_SIGNING_KEY` ใน Vercel
ซึ่งต้อง **ตรงกับ** แถวชื่อ `app-rpc` ในตาราง `private.application_signing_keys` ของ Supabase
ถ้าจะเปลี่ยน ต้องเปลี่ยนทั้งสองที่พร้อมกัน (รายละเอียดใน `docs/data-durability-and-operations.md`)

<a id="email"></a>
### อีเมลแจ้งปัญหา

รายงานจากหน้าแจ้งปัญหาส่งผ่าน Resend ไปที่อีเมลใน `FEEDBACK_EMAIL` ถ้าไม่ได้ตั้ง
จะไปที่ Gmail ของ Palm **เมื่อรับช่วง ให้ตั้ง `FEEDBACK_EMAIL` เป็นอีเมลของผู้ดูแลคนใหม่**

<a id="connectors"></a>
### เชื่อม Google Drive และ Notion

ปุ่มเชื่อมบัญชีซ่อนอยู่จนกว่าจะมี OAuth client ของ Google (`GOOGLE_OAUTH_CLIENT_ID`,
`GOOGLE_OAUTH_CLIENT_SECRET`, `GOOGLE_PICKER_API_KEY`) และของ Notion
(`NOTION_OAUTH_CLIENT_ID`, `NOTION_OAUTH_CLIENT_SECRET`) กับ `EXTERNAL_OAUTH_STATE_SECRET`
ใน Vercel เอกสาร Google ที่เปิดสาธารณะยังเปิดได้โดยไม่ต้องเชื่อม

<a id="domain"></a>
### โดเมน vetmock.com

จดกับ Cloudflare Registrar หมดอายุ 25 ก.ย. 2570 (ตรวจ 28 ต.ค. 2569) Cloudflare ต่ออายุ
อัตโนมัติถ้าบัตรในบัญชียังใช้ได้ ถ้าโดเมนหลุด ทุกเว็บของ VetMock เข้าไม่ได้ทันที การ์ดเตือน
ก่อน 60 วัน DNSSEC เปิดแล้ว

<a id="supabase"></a>
### Supabase หยุดโปรเจกต์ (แผน Free)

แผน Free ของ Supabase หยุดโปรเจกต์ที่ไม่มีใครใช้นานประมาณ 7 วัน เช่นช่วงปิดเทอม VetMock
จึงมี cron ใน `vercel.json` เรียก `/api/ai-chat?warm=1` วันละครั้ง ซึ่งค้นในคลังเอกสารหนึ่งครั้ง
(Supabase เป็นคนกำหนดว่าอะไรนับเป็นการใช้งาน วิธีนี้ใช้กันทั่วไปแต่ไม่มีใครรับประกัน)
ถ้าโปรเจกต์ถูกหยุดไปแล้ว เจ้าของบัญชี Supabase กด Restore ได้ที่ supabase.com/dashboard
และอีเมลเตือนก่อนหยุดจะไปที่เจ้าของบัญชี วิธีที่แน่นอนกว่าคือย้ายไปแผน Pro (มีค่าใช้จ่าย)

## 8. ส่งต่อให้ผู้ดูแลคนใหม่

ทำทีละข้อ และให้ทั้งสองคนอยู่ด้วยกันตอนทำ

1. **GitHub:** เพิ่มคนใหม่เป็น collaborator ระดับ Admin ของ `palmzamak2547/vet-mock`
   หรือโอน repo ให้ ถ้าโอน ต้องเชื่อม Git ของโปรเจกต์ใน Vercel ใหม่
2. **Vercel:** เชิญเข้าทีม และย้ายการจ่ายเงินแผน Pro ไปที่บัตรของคนใหม่ก่อนบัตรเดิมใช้ไม่ได้
3. **Supabase:** เชิญเข้า organization ระดับ Owner
4. **Cloudflare:** เพิ่มเป็นสมาชิกของ account และย้ายบัตรที่ใช้ต่ออายุโดเมน
5. **บริการที่เหลือ** (Upstash, Resend, DeepSeek, Anthropic, iApp, Google Cloud, LINE):
   โอนบัญชี หรือสร้างบัญชีใหม่แล้วเปลี่ยนคีย์ใน Vercel ทีละตัว แล้วเปิดหน้าแอดมินดูว่าทุกแถวยังปกติ
6. **บัญชีผู้ดูแล:** ให้คนใหม่เข้าสู่ระบบ vetmock.com หนึ่งครั้ง แล้วใน Supabase
   (SQL Editor) หา id ของเขาจาก `auth.users` ตามอีเมล และเพิ่มแถวใน `public.admin_users`
   ```sql
   insert into public.admin_users (user_id)
   select id from auth.users where email = 'อีเมลของคนใหม่';
   ```
7. **อีเมลแจ้งปัญหา:** ตั้ง `FEEDBACK_EMAIL` เป็นอีเมลของคนใหม่
8. **สคริปต์ MyCourseVille:** ส่งโฟลเดอร์ `.mcv/` ให้คนใหม่โดยตรง (หัวข้อ 6)

## 9. สำหรับคนที่แก้โค้ด
