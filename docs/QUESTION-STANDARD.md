> ทุกชั้นปีใช้มาตรฐานเดียวกัน และมาตรฐานนี้ต้องดีขึ้นเรื่อยๆ
>
> ไม่ใช่แค่สร้างข้อสอบขึ้นมา — ต้องถูกต้องและ make sense ด้วย

เอกสารนี้คือมาตรฐานฉบับคนอ่าน. ฉบับที่เครื่องอ่านคือ
[`scripts/lib/question-standard.mjs`](../scripts/lib/question-standard.mjs) —

ดูสถานะปัจจุบันของทั้งคลัง:

```bash
npm run lint:question-standard
```

## ส่วนที่ 1 — Defects (ต้องเป็นศูนย์)

ข้อไหนติดข้อใดข้อหนึ่ง = เสีย ไม่ใช่แค่ "ยังไม่ดี". `build-question-bank.mjs`
**ทิ้ง** ทันที ไม่พยายามซ่อม — ข้อที่ถูกสคริปต์ "แก้ให้เงียบๆ" คือข้อที่ไม่มีใครอ่าน.

### D1 · โจทย์ต้องยืนอยู่ได้ด้วยตัวเอง

สไลด์คือ**ที่มาของคำตอบ** ไม่ใช่ส่วนหนึ่งของคำถาม. คนที่ไม่เคยเห็นเด็คต้องตอบได้.

```
✗ ตามสไลด์ eccrine glands ในสุนัขและแมว พบที่ไหน
✓ Eccrine glands (true sweat glands) ในสุนัขและแมว พบที่ไหน
```

รวมถึงห้ามถาม**ตำแหน่งในเอกสาร** — "ข้อที่ 7 ของ checklist", "ตำแหน่งหมายเลข 11
ในแผนภาพ", "กล่องที่อาจารย์กากบาททับไว้" — และห้ามถาม**เรื่องธุรการของวิชา**
(เข้าเรียนกี่%, เกณฑ์ให้คะแนน, Bloom's taxonomy ในสไลด์แนะนำรายวิชา).
สิ่งเหล่านี้ไม่ใช่ความรู้ทางสัตวแพทย์.

### D2 · คำอธิบายก็ห้ามเล่าถึงเอกสาร

ข้อนี้เคยถูกมองข้าม เพราะกฎเดิมพูดถึงแต่ตัวโจทย์.

```
✗ สไลด์ให้ไทม์ไลน์ไว้เป็นชุดว่า obvious at 1-2-month-old chicken…
✓ Bursa of Fabricius เห็นชัดที่ 1-2 เดือน ถดถอยที่ 8-12 เดือน…
```

### D3 · ต้องมีที่มาเสมอ

`verified` (เด็ค + หน้า) หรือ `examOrigin` (ข้อสอบเก่าจริง) หรือ `source`.

### D4 · ถามถึงรูป ต้องมีรูป

Palm: *"ทำไมบางคำถามที่ต้องใช้รูปตอบถึงไม่เอารูปมาด้วย หรือบางคำถามแค่นี้ไม่สามารถตอบได้"*

```
✗ จากผล efficacy test ... ที่ 90 และ 120 วันหลังให้วัคซีน
  เส้นของ Formalin killed vaccine (WC) เป็นอย่างไร        ← ไม่มีกราฟ = ตอบไม่ได้
```

**⚖️ แต่ "อ้างถึงรูป" กับ "ต้องใช้รูป" ไม่ใช่เรื่องเดียวกัน — ยาคนละขนาน**

ถามตัวเองข้อเดียว: **คำตอบอยู่ในรูป หรืออยู่ในหัวนิสิต?**

| | ตัวอย่างจริง | ต้องทำ |
|---|---|---|
| **คำตอบอยู่ในรูป**<br>(ค่าที่ต้องอ่าน · สัดส่วน · เส้นอยู่ตรงไหน · ลูกศรชี้อะไร) | *"เส้นของ Formalin killed vaccine (WC) ที่ 90 และ 120 วันเป็นอย่างไร"*<br>*"ผลผลิตรวม 541,239 ตัน กลุ่มใดสัดส่วนมากสุด คิดเป็นเท่าใด"* | **แนบรูปจริง** |
| **คำตอบเป็นความรู้**<br>(รูปเป็นแค่ภาพประกอบของเหตุผลที่ควรคิดเองได้) | *"ตามแผนผัง striatum คร่อมนิวเคลียสใดบ้าง"* → caudate + accumbens + putamen เป็น neuroanatomy มาตรฐาน<br>*"ตามผัง LGN → optic radiation เข้าสู่โครงสร้างใด"* | **ลบคำอ้างอิงทิ้ง**<br>ไม่ต้องแนบรูป |
| **ไม่ได้อ้างถึงรูปเลย**<br>(คำนั้นเป็นส่วนหนึ่งของนิยาม) | *"Conceptual Biosecurity = แผนผังโครงสร้างฟาร์ม"*<br>*"แผนภูมิ HACCP ต้องครอบคลุมถึงขั้นตอนใด"* | **ประกาศยกเว้น**พร้อมเหตุผล |

⚠️ **จุดที่ผูกโจทย์ไว้กับรูปโดยไม่รู้ตัว = เลขลำดับ** เช่น *"กลับไปขั้นตอนที่ 2"* —
เลข 2 มีอยู่แค่บนผังใบนั้น เปลี่ยนเป็น**ชื่อขั้น**แล้วโจทย์ยืนได้เอง ทดสอบความเข้าใจจริงด้วย
(ทำให้ดูแล้วที่ `#105206` นาโนวัคซีน — ไม่ได้แนบรูป แต่เอาเลขออกและตั้งชื่อขั้นแทน)

ถ้าเข้าเกณฑ์แถวแรก ต้องแนบรูปจริง (`image: '/figures/questions/q<id>.webp'`)
ไม่งั้นคือข้อที่ไม่มีใครตอบได้

⚠️ **"ในรูป X" ไม่นับ** — เป็นสำนวนไทยแปลว่า *in the form of*
("cholesterol ในรูป LDL", "premix ในรูปของสารผสมล่วงหน้า") กฎรอบแรกจับพวกนี้ไปด้วย
คิดเป็น **1 ใน 3** ของที่ flag มา

ข้อที่เอ่ยถึงรูปแต่**บอกทุกอย่างที่รูปจะบอกไว้แล้ว** = ตอบได้ ให้ประกาศไว้ใน
[`src/data/figure-exempt.js`](../src/data/figure-exempt.js) พร้อมเหตุผล
ไม่ใช่ไปเจาะรูใน regex เงียบๆ (มี gate ตรวจว่า id ที่ยกเว้นยังมีอยู่จริง)

### D5 · `examOrigin` แปลว่าข้อสอบเก่าจริงเท่านั้น

`examOrigin: 'COM III Final 2019'` ✓ — `examOrigin: 'Equine Med deck (Vet 85)'` ✗.
เด็คคือ `source`. การเอาชื่อเด็คใส่ `examOrigin` ทำให้ข้อที่เขียนจากสไลด์
**สวมอำนาจของข้อสอบเก่า** ซึ่งไม่จริง.

### C1 · คำอธิบายมี 3 ท่อน

```
<ทำไมข้อที่ถูกถึงถูก — กลไกหรือตัวเลข พูดตรงๆ>

❌ ทำไมข้ออื่นผิด
— "<ตัวลวง>" = <จริงๆ มันคืออะไร หรือมันอยู่ตรงไหน>
— "<ตัวลวง>" = <…>

💡 <ตัวช่วยจำสั้นๆ เฉพาะเมื่อมีจริง>
```

ต้องอธิบาย**ทุกตัวลวง** ไม่ใช่เฉพาะตัวที่ล่อที่สุด. ถ้าไม่มีตัวช่วยจำที่ซื่อสัตย์
ให้ตัดบรรทัด 💡 ทิ้ง อย่าแต่งขึ้นมา.

### C3 · จำนวนตัวเลือกต้องหลากหลาย (4 หรือ 5)

## ส่วนที่ 3 — กฎกันเดา (มีมาก่อน ยังใช้อยู่)

- ข้อถูกต้องห้ามยาวกว่าตัวลวงอย่างเห็นได้ชัด (builder ตัดที่ 1.5× ค่าเฉลี่ย)
- ห้าม `★` `**ตัวหนา**` `…` จุดกลาง ในตัวเลือก
- ห้าม "ถูกทุกข้อ" / "ไม่มีข้อใดถูก"
- ตัวลวงต้องเป็นของจริงที่วางผิดที่ ไม่ใช่ของที่แต่งขึ้น; ตัวเลขต้องอยู่ scale เดียวกัน
- กระจายตำแหน่งคำตอบ อย่ากองที่ index เดียว
- ไวยากรณ์ของโจทย์ต้องเข้ากับทุกตัวเลือก

## ส่วนที่ 4 — "ถูกต้องและ make sense"

Gate ทุกตัวข้างบนเป็นเรื่องกลไก. ข้อสอบผ่านทุก gate แล้วยัง**ผิด**ได้.
สองอย่างที่กลไกจับไม่ได้ ต้องใช้คนหรือ agent ที่แยกอิสระ:

**4.1 ตัดที่มาออกแล้ว คำตอบยังเป็นคำตอบเดียวที่ถูกอยู่ไหม**
ตัวอย่างจริงจากรอบล่าสุด 3 ข้อที่**ต้องทิ้ง ไม่ใช่แก้**:
- SCC cut-off 200,000 กับ 400,000 ต่างก็เป็นเกณฑ์จริงที่มีใช้
- CCP numbering — สามตัวเลือกเป็น CCP จริงพร้อม critical limit จริงทั้งหมด
- pasteurization 72-75°C/15-20 s เป็นค่ามาตรฐาน พอๆ กับ 83-85°C ที่สไลด์ระบุ

พอตัด "ตามสไลด์" ออก ข้อพวกนี้กลายเป็นข้อที่มีคำตอบถูกมากกว่าหนึ่ง.
**ทิ้งดีกว่าปล่อยไว้.**

**4.2 การแก้ต้องไม่เพิ่มข้อมูลใหม่**
ตอนแก้โจทย์ ทุกตัวเลข ทุกชื่อเชื้อ ทุกคำอังกฤษในโจทย์ใหม่
ต้องเคยอยู่ในโจทย์เดิม — ตรวจด้วยเครื่องได้ และควรตรวจ.
